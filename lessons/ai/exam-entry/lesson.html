2차시에 했던 것처럼 엔트리로 이미지 분류 인공지능 모델을 만들어요. 아래 단계를 따라 모델을 완성하고, 결과 화면을 캡처해 붙인 뒤 문항에 답해요.

MAKE_MODEL35 STEPS

이미지 분류 인공지능 모델

1. 엔트리 과제 열기
  1. 1엔트리에 들어가요.
    ↗ 엔트리 열기
  2. 2로그인 클릭
  3. 3(1) 로고 클릭 (2) 나의 학급 클릭

  5. 5과제 시작하기 클릭
2. 이미지 분류 모델 만들기
  1. 6(1) 인공지능 클릭 (2) 인공지능 모델 학습하기 클릭
  2. 7(1) 새로 만들기 클릭 (2) 분류: 이미지 클릭
  3. 8맨 위 오른쪽에 학습하기 클릭
  4. 9내가 구분시킬 것 2개 적어주기. 000과 000 이미지 구분하는 인공지능 모델. (아무거나 내 마음대로)
  5. 10구분할 것 이름 적어주기
3. 학습 데이터 모으기
  1. 11(1) 구글 들어가기 (2) 내가 원하는 거 검색 (3) 이미지 클릭
  2. 12원하는 이미지 클릭
  3. 13옆에 크게 뜨면, Windows + Shift + S 눌러서 캡처하기
  4. 14(1) 폴더 클릭 (2) 사진 클릭 (3) 스크린샷 클릭
  5. 15스크린샷 파일 생겼는지 확인
  6. 16엔트리 다시 들어가서, 해당 부분 클릭
  7. 17(1) 파일 업로드 클릭 (2) 사진 클릭 (3) 스크린샷 클릭
  8. 18(1) 원하는 사진 클릭 (2) 열기 클릭
  9. 19이렇게 사진이 들어가면 성공
  10. 20이렇게 구분할 것마다 사진을 5개 이상 넣어 주세요. (예: 카리나 사진 5개 이상, 장원영 사진 5개 이상)
  11. 215개 이상 준비!!!
4. 모델 학습시키기
  1. 22다 됐다면 학습하기 클릭해서 인공지능 모델 학습시키기
5. 테스트하기
  1. 23100% 완료될 동안, 테스트할 때 쓸 데이터를 구글에서 캡처하기
  2. 24100% 완료됐다면, 파일 업로드 클릭
  3. 25(1) 사진 클릭 (2) 스크린샷 클릭
  4. 26(1) 테스트에 쓸 사진 클릭 (2) 열기 클릭
  5. 27인공지능 모델 완성
6. 블록 만들고 제출하기
  1. 28맨 위 오른쪽에 적용하기 누르기
