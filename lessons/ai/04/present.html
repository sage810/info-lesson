오늘 배운 것 — 인공지능 시스템은 4단계로 문제를 풀어요

단계하는 일유튜브 추천에서는
문제 해결에 필요한 데이터를 모아요사람들의 시청 기록·좋아요 모으기
데이터 속 을 찾아 모델을 만들어요「이 영상 본 사람은 저 영상도 좋아한다」 패턴 찾기
처음 보는 데이터의 결과를 판단해요내가 좋아할 영상 판단하기
예측 결과로 문제를 해결해요홈 화면에 추천 영상 보여 주기

결과 활용에서 생긴 새 가 다시 입력되어,
인공지능 시스템은 쓸수록 더 똑똑해져요.

형성평가 — O / X (1~3)

1인공지능 시스템은 데이터를 학습한 인공지능 모델을 이용해 문제를 해결한다.
2인스타그램 필터에서 얼굴의 눈·코·입 위치를 판단하는 부분은 인공지능 모델이다.
3인공지능 시스템은 예측 → 학습 → 데이터 입력 → 결과 활용 순서로 문제를 해결한다.

형성평가 — O / X (4~5)

4데이터를 많이 모아 두기만 하면 학습하지 않아도 인공지능 모델이 정확히 예측할 수 있다.
5내가 추천 영상을 누르거나 넘긴 기록은 다시 새 데이터가 되어 추천 AI를 더 똑똑하게 만든다.
