### 전개 · ACTIVITY_1 — 우리 반 AI 성적표 — 왜 우리가 만든 인공지능마다 성능이 다를까?
- 다섯 친구가 똑같이 엔트리로 「분식 분류 AI(떡볶이·마라탕·탕후루)」를 만들었어요. 그런데 성적이 제각각이에요!
- 표(개발자 · 학습 데이터는 이렇게 모았어요 · 테스트 결과) 5줄 — 양식 그대로(제나 · 원이 🏆 · 메이 · 미나미 · 리브).
- 그림(SVG 새로 그림 `assets/a1-class.svg`): 다섯 AI 로봇이 테스트 사진(떡볶이)을 보고 답하는 만화 — 원이 AI 만 「떡볶이!」 정답, 나머지 넷은 머리 위 물음표와 엉뚱한 답(「탕후루?」「떡볶이…?」 등). **그림이 2번 이름표 정답(원인)을 알려 주지 않게** 원인 글자는 넣지 않는다.
1. 하나 고르기(누르면 바로 채점): 다섯 친구의 AI 실력이 서로 다른 가장 큰 까닭은 무엇일까요?
   - **학습에 쓴 데이터가 서로 달라서 (정답)** — 맞았을 때 이유(Claude 초안): 같은 엔트리로 만들어도 넣은 데이터가 다르면 AI가 배운 것도 달라요.
   - 엔트리 버전이 서로 달라서 — ✗ 모두 같은 엔트리로 만들었어요. 달라진 건 넣은 데이터예요.
   - 컴퓨터 성능이 서로 달라서 — ✗ 컴퓨터가 빨라도 데이터가 부실하면 AI는 잘 못 맞혀요.
2. 친구들의 AI가 틀린 원인을 찾아 이름표를 붙여요. (이름표 4개 · ✅ 정답 확인)
   - 제나 — 클래스마다 5장뿐이라 패턴을 찾기엔 너무 적어요 → 데이터 양이 부족해요
   - 메이 — 탕후루만 6장이라 AI가 탕후루를 거의 못 배웠어요 → 클래스끼리 데이터 수가 불균형해요
   - 미나미 — 떡볶이 사진에 「마라탕」 정답이 붙어 AI가 잘못 배웠어요 → 레이블이 잘못 붙었어요
   - 리브 — 흰 접시 위 음식만 봐서 급식판 위 음식은 처음 보는 것처럼 느껴요 → 데이터가 다양하지 않아요
   - 안내 상자: AI는 데이터에서 패턴을 찾아 배워요. 데이터가 적으면 배울 게 부족하고, 치우치면 한쪽만 배우고, 정답이 틀리면 틀린 걸 배우고, 한 가지 모습만 보면 다른 모습은 못 알아봐요. 그래서 AI의 실력은 결국 데이터가 결정해요!

### 전개 · ACTIVITY_2 — 유튜브 추천 AI는 4단계로 문제를 풀어요
- 그림(SVG 새로 그림 `assets/a2-steps.svg`): ① 데이터 입력 → ② 학습 → ③ 예측(판단) → ④ 결과 활용 네 칸 화살표, ④ → ① 점선 화살표 옆 「새 데이터가 다시 들어가요」. 각 칸에는 단계 이름만(1번 표 빈칸 정답 — 데이터·패턴·예측·문제 — 을 그림이 알려 주지 않게, 단계 이름 「예측」은 표 첫 칸에도 있어 그대로 둠).
1. 인공지능 시스템이 문제를 해결하는 4단계에서 각 단계가 하는 일을 완성해요. — 표(단계 · 하는 일 · 비유하면?), 글자 빈칸 4개(채점 없음, 정답지에만): 데이터 · 패턴 · 예측 · 문제
2. 유튜브 추천 AI가 하는 일이에요. 각각 몇 단계일까요? (이름표: 데이터 입력, 학습, 예측, 결과 활용 · ✅ 정답 확인)
   - 전 세계 사람들의 시청 기록·좋아요·시청 시간을 모아요 → 데이터 입력
   - 「게임 공략을 끝까지 본 사람은 다른 게임 공략도 자주 본다」 같은 패턴을 찾아 추천 모델을 만들어요 → 학습
   - 내가 어제 본 영상을 보고 「이 사람은 이 영상을 좋아할 확률 92%」라고 판단해요 → 예측
   - 좋아할 확률이 높은 영상을 내 홈 화면 맨 위에 보여 줘요 → 결과 활용
   - 안내 상자: 내가 추천 영상을 누르거나 넘기면 그것이 다시 새 데이터가 돼요. 그래서 유튜브를 쓸수록 추천이 점점 내 취향에 맞아져요.
3. 하나 고르기(누르면 바로 채점): 막 만든 추천 AI에게 ② 학습 단계를 건너뛰고 바로 영상을 추천하라고 하면 어떻게 될까요?
   - **아무 영상이나 추천해서 내 취향을 못 맞힌다 (정답)** — 맞았을 때 이유(Claude 초안): 학습하지 않으면 판단 기준이 되는 모델이 없어서 아무거나 골라요.
   - 데이터만 있으면 되니까 학습한 것과 똑같이 잘 맞힌다 — ✗ 데이터를 모아만 두고 패턴을 찾지 않으면 판단 기준이 되는 모델이 없어요.
   - 추천 영상이 하나도 안 나온다 — ✗ 추천은 나오지만, 배운 게 없어 아무거나 골라요.
4. 순서 배열 — 이번엔 게임 속 AI예요. 게임 회사가 핵(불법 프로그램) 사용자를 잡아내는 과정(섞어서 보여 줌, ✅ 순서 확인)
   1) 정상 플레이어와 핵 사용자의 플레이 기록(조준 속도, 명중률, 움직임)을 아주 많이 모아요.
   2) 「핵 사용자는 사람이 할 수 없을 만큼 조준이 빠르고 정확하다」는 패턴을 학습해 핵 탐지 모델을 만들어요.
   3) 새로 게임한 플레이어의 기록을 모델이 보고 핵을 썼는지 예측해요.
   4) 핵 사용자로 판단되면 경고를 보내거나 계정을 정지해 공정한 게임을 지켜요.
   - 피드백(Claude 초안): 모두 맞음 「정확해요! 데이터 입력 → 학습 → 예측 → 결과 활용 순서예요.」 / 일부 「모델을 만들려면 먼저 기록을 모아야 하고, 계정 정지는 모델이 판단한 뒤에 해요. 빨간 칸을 다시 옮겨 봐요.」 / 하나도 안 맞음 「4단계를 떠올려 봐요 — 데이터 입력 → 학습 → 예측 → 결과 활용.」 / 빈 칸 「빈 칸이 있어요. 4칸을 모두 채운 뒤 '순서 확인'을 눌러요.」
