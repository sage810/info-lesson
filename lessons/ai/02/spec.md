### 전개 · ACTIVITY_2 — 내 모델 결과 기록하기 (Claude 초안)
1. 내가 만든 모델 — 문장 빈칸(정답 없음)
   - 내가 만든 모델: [ 빈칸 ]와(과) [ 빈칸 ]를 구분하는 인공지능 모델
   - 학습 데이터는 각각 [ 빈칸 ]개, [ 빈칸 ]개를 수집해 학습시킴   (문장 모양 선생님 피드백 2026-10-23)
2. 테스트 결과 — 문장 빈칸(정답 없음) + 붙여넣기 칸
   - 테스트 데이터로 인공지능 모델에게 준 것: [ 빈칸 ]
   - 인공지능 모델이 분류한 결과: [ 빈칸 ]
   - 확률: [ 빈칸 ]%   (세 줄로 — 피드백 2026-10-23)
   - 붙여넣기 칸: 결과 화면(분류한 클래스와 %) 캡처
3. 하나 고르기(누르면 바로 채점): 모델이 테스트 사진을 틀리게 분류했어요. 더 잘 맞히게 하려면 어떻게 해야 할까요?
   - **클래스마다 학습 데이터를 더 많이, 더 다양하게 넣고 다시 학습시킨다 (정답)** — ✓ 이유: 모델은 본 데이터만큼 배워요. 여러 모습의 사진을 볼수록 처음 보는 사진도 잘 맞혀요
   - 테스트 사진을 학습 데이터에 넣었던 사진으로 바꾼다 — ✗ 이유: 이미 본 사진으로 시험하면 진짜 실력을 알 수 없어요. 테스트는 처음 보는 사진으로 해요
   - 학습하기 버튼을 여러 번 누른다 — ✗ 이유: 같은 데이터로 다시 학습해도 배운 내용은 같아요. 데이터를 바꿔야 해요

### 정리 · KEY_SUMMARY — 오늘 배운 것 — 모델은 학습 데이터로 배워요 (Claude 초안)
표(낱말 칸·뜻 칸 모두 이름표 칸) — 낱말 | 뜻   (「오늘 실습에서」 열 · 아래 문장 · 「같은 이름표를 두 번 써도 돼요」 삭제 — 피드백 2026-10-23)
| 낱말 | 뜻 |
|---|---|
| [클래스] | 모델이 나누어 담는 [이름] |
| [학습 데이터] | 모델을 [학습]시키려고 클래스마다 넣어 준 사진 |
| [테스트 데이터] | 학습에 쓰지 않은 [새로운] 사진 |
- 이름표 모음(9개 섞음): 클래스 · 학습 데이터 · 테스트 데이터 · 이름 · 학습 · 새로운 + 헷갈리게 「확률」 · 「규칙」 · 「정답」

### 정리 · CHECK_UP — 형성평가 O / X (Claude 초안)
(처음 1번 「엔트리 이미지 분류 모델은 클래스마다 이미지를 5개 이상 넣어야 학습할 수 있다」 · 5번 「한 번 학습을 마친 인공지능 모델은 절대 틀리지 않는다」는 삭제 — 피드백 2026-10-23)
1. 테스트할 때는 학습 데이터로 넣었던 사진을 그대로 쓰는 것이 가장 좋다. → X (이유: 이미 본 사진은 맞히기 쉬워서 진짜 실력을 알 수 없어요. 처음 보는 사진으로 시험해요)
2. 분류 결과에 나오는 %는 모델이 그 클래스라고 생각하는 정도(확률)이다. → O (이유: 카리나 17%, 장원영 83%처럼 더 높은 쪽으로 분류해요)
3. 학습 데이터가 많고 다양할수록 처음 보는 사진도 잘 맞힐 가능성이 높다. → O (이유: 여러 모습을 보고 배운 모델일수록 새 사진의 특징도 잘 찾아요)
