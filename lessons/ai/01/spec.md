- 1. 「시작하기」를 누르고 제시어 6개를 그려요. AI가 몇 개를 맞혔는지 적어요. — 내 그림: [ 빈칸 ]개 맞힘 / 6 개 (정답 없음)
- 2. 컴퓨터는 어떻게 내 그림을 알아맞혔을까요? 내 생각을 적어 봐요. — 쓰기 칸 2줄(정답 없음)

### 도입 · TODAY_TOPIC — 오늘은 인공지능의 정체를 밝혀요
- 유튜브·틱톡 추천과 인스타 필터 속 인공지능은 어떻게 똑똑해질까요? 인공지능과 인공지능 모델이 무엇인지 알아보고, 인공지능인 것과 아닌 것을 가려내요.

### 전개 · ACTIVITY_1 — 인공지능은 어떻게 내 낙서를 알아봤을까?
1. 영상으로 인공 신경망을 만나 봐요(약 50초). — 버튼 「소프트웨어야 놀자 「딥러닝(심층학습)」 0:16부터 보기」 → https://www.youtube.com/watch?v=bndGqgide60&t=16s
   - Tip: 1:06에서 멈춰요. 고양이와 강아지를 구별하지 못하던 아기가 어떻게 구별하게 되는지 눈여겨봐요.
2. 읽고 빈칸을 채워요. (문장 속 글자 빈칸 — **채점 없음**, 정답지에만)
   - 사람의 학습·인식·추론 같은 지적 능력을 흉내 내어 소프트웨어로 만든 것을 [인공지능]이라고 해요.
   - 사람의 뇌에서는 수많은 신경 세포(뉴런)가 신호를 주고받으며 배워요. 이 모습을 흉내 내어 만든 구조가 [인공 신경망]이에요.
   - 인공 신경망은 많은 데이터를 보면서 스스로 패턴을 찾아요. 이렇게 데이터로 배우는 과정을 학습이라고 해요.
   - 학습을 마치고 만들어진 결과물을 [인공지능 모델]이라고 해요. 모델은 처음 보는 데이터가 들어와도 무엇인지 분류하거나 예측해요.
   - 그림(SVG 새로 그림): 왼쪽 뇌 속 뉴런들이 신호를 주고받는 모습 / 오른쪽 동그라미(인공 뉴런)가 여러 층으로 선을 따라 이어진 인공 신경망, 입력 고양이 낙서 → 출력 「고양이 90%」.
     그림 안 글자는 「사람의 뇌」「컴퓨터 속 구조」「인공 뉴런」「입력」「출력」뿐 — **빈칸 정답(인공 신경망 · 인공지능 모델)을 그림이 알려 주지 않게** 했다.
3. 순서 배열 — Quick, Draw!의 AI가 내 낙서를 알아맞히기까지(활동지에서는 섞어서 보여 줌, ✅ 순서 확인 버튼)
   1) 전 세계 사람들이 Quick, Draw!에서 그린 낙서 5천만 개를 모아요.
   2) 인공 신경망이 낙서를 보며 「고양이는 뾰족한 귀와 수염」 같은 패턴을 학습해요.
   3) 학습 결과로 「낙서 알아맞히기」 인공지능 모델이 만들어져요.
   4) 내가 새로 그린 낙서를 모델이 보고 무엇인지 예측해요.
   - 피드백(Claude 초안): 모두 맞음 「정확해요! 데이터를 모으고 → 학습하고 → 모델이 만들어진 뒤 → 새 낙서를 예측해요.」 /
     일부 「4칸 중 N칸이 제자리예요. 학습하려면 먼저 데이터가 있어야 하고, 예측은 모델이 다 만들어진 뒤에 해요.」 /
     빈 칸 「빈 칸이 있어요. 4칸을 모두 채운 뒤 '순서 확인'을 눌러요.」
4. 게임 실력에 빗대면 무엇일까요? 알맞은 이름표를 끌어다 놓아요. (이름표: 인공 신경망, 학습, 인공지능 모델 · ✅ 정답 확인)
   - 뇌처럼 서로 연결되어 있어서, 연습하면 배울 수 있는 머리 → 인공 신경망
   - 수백 판을 하면서 「이럴 땐 이렇게!」를 몸에 익히는 연습 → 학습
   - 연습을 마치고 처음 만나는 상대와의 실전에서 발휘하는 실력 → 인공지능 모델

### 전개 · ACTIVITY_2 — 인공지능일까, 아닐까?
1. 구분하는 기준을 알아봐요.
   - 안내 상자: 기준은 「학습했나?」 하나예요 — 인공지능 소프트웨어는 데이터로 학습한 인공지능 모델을 써서 스스로 판단해요. 일반 소프트웨어는 사람이 미리 정해 둔 규칙과 순서대로만 움직여요.
   - 그림(SVG 새로 그림): 두 줄 비교 — 위: 사람이 정한 규칙 + 입력 → 일반 소프트웨어 → 늘 같은 결과 / 아래: 데이터 → 학습 → 인공지능 모델, 새 입력 → 모델 → 예측.
2. 내 폰 속 기능을 나눠 봐요. (이름표: 인공지능, 일반 소프트웨어 · ✅ 정답 확인)
   - 내가 끝까지 본 영상과 「좋아요」를 보고 다음 영상을 골라 주는 틱톡 추천 피드 → 인공지능
   - 얼굴을 찾아 강아지 귀와 코를 씌워 주는 인스타그램 필터 → 인공지능
   - 사귄 날짜를 넣으면 100일·200일을 계산해 주는 디데이 앱 → 일반 소프트웨어
   - 놀러 가서 쓴 돈을 사람 수로 똑같이 나눠 주는 1/N 정산 기능 → 일반 소프트웨어
   - 유튜브 영상 속 말소리를 알아듣고 글자로 바꿔 주는 자동 생성 자막 → 인공지능
   - 매일 아침 7시에 울리도록 맞춰 둔 알람 → 일반 소프트웨어
   - 사진첩에서 「바다」를 검색하면 바다 사진만 찾아 주는 기능 → 인공지능
   - 이름 획수를 정해진 공식으로 더해 점수를 내는 이름 궁합 테스트 → 일반 소프트웨어
3. 하나 고르기(누르면 바로 채점): 어떤 게임의 몬스터는 「AI」라고 불리지만, 개발자가 정해 둔 「플레이어가 세 칸 안에 오면 공격한다」 규칙대로만 움직여요. 학습을 기준으로 보면 이 몬스터를 움직이는 것은?
   - 인공지능 소프트웨어 — ✗ 이유: 이름에 AI가 붙어도 데이터로 학습하지 않고 정해진 규칙대로만 움직이면 일반 소프트웨어예요
   - **일반 소프트웨어 (정답)**

### 전개 · ACTIVITY_3 — 내가 AI 트레이너! 바다를 청소하는 AI를 학습시켜 볼까?
- AI for Oceans(바다를 위한 AI)에서 AI에게 물고기와 쓰레기를 구별하는 법을 가르쳐요. 내가 누르는 버튼 하나하나가 AI의 학습 데이터가 돼요.
1. 2단계부터 시작해요(1단계 영상은 건너뛰어요). — 버튼 「바다를 위한 AI 2단계 열기」 → https://studio.code.org/kr/courses/oceans/units/1/lessons/1/levels/2
2. 1차 학습 — 「물고기」, 「물고기 아님」 버튼으로 라벨을 붙여요. 사진 아이콘 옆 숫자(카운터)가 6이 되면 바로 「계속」을 눌러요.
3. AI가 「물고기」로 고른 것 중에 쓰레기가 몇 개 섞였는지 세어 **적어요**.
   - 문장 빈칸(선생님 결정 「표 대신 문장 빈칸」, 문구는 Claude 초안): 1차 학습 뒤, 「물고기」로 고른 것 중 쓰레기: [ 빈칸 ]개 (정답 없음)
4. 2차 학습 — 「학습 더 하기」를 눌러 카운터가 30을 넘을 때까지 라벨을 더 붙이고 「계속」을 눌러요. 다시 세어 **적어요**.
   - 문장 빈칸(Claude 초안): 2차 학습 뒤, 「물고기」로 고른 것 중 쓰레기: [ 빈칸 ]개 (정답 없음)
   - 양식의 「표에 적어요」는 「적어요」로 바꿈(표가 없어서).
5. 「계속」을 눌러 3단계를 보고 답해요. — 하나 고르기(누르면 바로 채점): AI가 바다 생물 몇몇(게, 문어, 거북 등)까지 「물고기 아님」으로 골라냈어요. 왜 그랬을까요?
   - AI가 고장 나서 — ✗ 이유: AI는 고장 나지 않았어요. 배운 대로 했을 뿐이에요
   - **학습 데이터에 물고기와 쓰레기만 있어서, 바다 생물은 배운 적이 없어서 (정답)**
   - 바다 생물은 바다에 있으면 안 돼서 — ✗ 이유: 바다 생물도 바닷속에 있어야 해요. AI는 우리가 가르친 것만 배워요
6. 4단계에서는 「바닷속에 있는 게 맞습니까?」에 「예」, 「아니요」로 답하며 AI를 다시 학습시켜요. 이번에는 바다 생물을 지켜 냈나요?
   - 쓰기 칸 1줄, 연한 예시 글: 거북과 게는 바다에 남겼는데, 해파리는 골라냈어요. (정답 없음 — 정답지에서 비움)
   - 붙여넣기 칸: 4단계에서 AI가 「바닷속에 속함」으로 고른 결과 화면 캡처

### 전개 · ACTIVITY_4 — AI의 밥, 데이터
1. 데이터에 관한 낱말 세 가지를 알아봐요.
   - 안내 상자 「레이블 · 학습 데이터 · 테스트 데이터」: 레이블(라벨)은 데이터에 붙인 정답 이름표예요. 인스타 사진에 #떡볶이를 다는 것처럼, 사진에 「고양이」라고 붙이는 거예요. 학습 데이터는 모델을 학습시키려고 레이블과 함께 보여 주는 데이터예요. 테스트 데이터는 학습을 마친 모델이 얼마나 잘 맞히는지 확인하려고 쓰는, 학습에 쓰지 않은 새로운 데이터예요.
   - Tip: 시험공부와 같아요. 문제집으로 공부하는 것이 학습 데이터, 처음 보는 시험 문제로 실력을 확인하는 것이 테스트 데이터예요. 문제집 문제가 그대로 시험에 나오면 진짜 실력을 알 수 없겠죠?
2. 방금 한 AI for Oceans에서 찾아봐요. (이름표: 레이블, 학습 데이터, 테스트 데이터 · ✅ 정답 확인)
   - 내가 버튼으로 붙인 「물고기」, 「물고기 아님」 → 레이블
   - 내가 라벨을 붙여 가며 AI에게 보여 준 그림들 → 학습 데이터
   - 학습이 끝난 뒤 AI가 처음 보고 분류한 바닷속 물체들 → 테스트 데이터
3. 하나 고르기(누르면 바로 채점): 내 취향을 맞히는 영상 추천 AI를 만들었어요. 이 AI가 잘 맞히는지 확인하려면 어떤 데이터로 시험해야 할까요?
   - 학습할 때 이미 보여 준 영상들 — ✗ 이유: 이미 본 문제로 시험을 보면 진짜 실력을 알 수 없어요
   - **학습에 쓰지 않은 새 영상들 (정답)**
4. AI가 엉뚱해진 까닭을 찾아 이름표를 끌어다 놓아요. (이름표: 데이터 양이 부족해요, 데이터 질이 나빠요 · ✅ 정답 확인)
   - 어제 만든 새 틱톡 계정이라 본 영상이 몇 개 없어서 추천이 내 취향과 전혀 달라요 → 데이터 양이 부족해요
