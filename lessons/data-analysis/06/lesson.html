📌 데이터 시각화의 4가지 유형

무엇을 알고 싶은가에 따라 4가지 유형으로 나누어서 그래프를 그려요.

유형의미질문 예시
구성 분석전체에서 각 그룹들이 각각 몇 %를 차지하는지 보는 것"~는 몇 %일까?"
비교 분석서로 다른 그룹끼리 누가 더 크고 작은지 비교하는 것"~과 ~ 중 어느 쪽이 더 클까?"
분포 분석데이터들이 주로 어디에 몰려있고 퍼져있는지 모양을 보는 것"~는 주로 어디에 몰려 있을까?"
"유난히 다른 값이 있을까?"
관계 분석두 속성 간에 어떤 관계가 있는지 파악하는 것"~랑 ~는 서로 관련이 있을까?"
🖥 CODAP에 데이터 올리기
  1. 구글에 '코답' 이라고 검색해요.
  2. 검색 결과에서 CODAP(codap.concord.org) 사이트를 클릭해요.
  3. 오른쪽 맨 위에 있는 주황색 Launch CODAP 버튼을 눌러요.
  4. 새 문서를 눌러요.
  5. 수업자료 폴더에 있는 포켓몬 파일을 CODAP의 흰 바탕 위로 끌어다 놓아요.
  6. 화면에 표가 생겼다면 완성!
    표의 모서리를 끌어 크기를 키워 데이터가 다 보이게 하고, 친구를 도와주세요.
① 구글에 '코답' 이라고 검색
② 검색 결과에서 CODAP(codap.concord.org) 클릭
③ 오른쪽 위 주황색 Launch CODAP 클릭
④ '어떤 작업을 할까요?'에서 '새 문서' 클릭
⑤ 포켓몬 파일을 CODAP 흰 바탕으로 끌어다 놓기
⑥ 표 모서리를 끌어 데이터가 다 보이게 늘리기
MISSION_2 DISTRIBUTE
🎬
분포 분석
📋 분포 분석이 뭘까요? 반 친구들의 시험 점수를 쭉 늘어놓았을 때 점수가 어느 구간에 많이 몰려있는지 살펴보는 것
💬 이렇게 질문해요 "우리 반 중간고사 수학 점수는 보통 어느 구간에 몰려 있을까?" 처럼 '어느 구간에 몰려 있는지', '유난히 다른 값(이상치)이 있는지' 묻는 질문이에요.
🧩 데이터 분석 과정
  • 1. [문제 정하기] 포켓몬들의 체력은 보통 어느 구간에 모여있을까?
  • 2. [데이터 수집 · 속성 파악] 살펴볼 값은 '체력' 속성이에요.
  • 3. [데이터 분석하기] 아래 순서대로 CODAP 그래프를 그려요.
🖥 CODAP 그래프 그리기
  1. 그래프 버튼을 눌러 새 그래프 창을 열어요.
  2. x축에 '체력' 속성을 클릭해요.
  3. Measure(측정) 클릭 → 그림 상자와 정규 곡선 클릭 → Box Plot 클릭.
  4. box plot 선이 뜬다면 완성이에요.
  5. 가운데 선에 마우스를 가져다 대면 중앙값, 양 끝 선에 대면 최솟값 · 최댓값을 확인할 수 있어요.
① 그래프 버튼을 눌러 새 그래프 창 열기
② x축을 클릭해 ③ '체력' 선택
④ Measure → ⑤ 그림 상자와 정규 곡선 → ⑥ Box Plot
가운데 선에 마우스 → 중앙값 확인 (예: 80)
끝 선에 마우스 → 최솟값 · 최댓값 확인 (예: 250)
PASTE 스샷으로 캡처하고 활동지에 붙여넣는 방법
빨간 칸이 윈도우키 ⊞ · Shift · S 위치. 세 개를 함께 눌러요.
  1. 위 사진처럼 키보드에서 윈도우키 ⊞ + Shift + S 를 함께 눌러요.
  2. 붙여넣고 싶은 부분을 마우스로 드래그해서 캡처해요.
  3. 아래 칸을 한 번 누른 뒤 Ctrl + V 를 눌러 캡처한 스샷을 붙여넣어요.

  • 4. [데이터 해석하기] 붙여넣은 그래프를 보고 알게 된 사실을 정리하고, 그것으로 어떤 결론을 내릴 수 있는지 생각해요.
🔎 이상치(outlier)가 무엇일까? 대부분의 값이 모여 있는 곳에서 혼자 멀리 동떨어져 있는 값이에요. 예를 들어 반 친구들의 키가 대부분 150~165cm인데 한 명만 195cm라면, 그 값이 이상치예요. 분포를 볼 때는 "유난히 튀는 값이 있는지"도 함께 살펴봐요.

MISSION_3 RELATE
🎬
관계 분석
📋 관계 분석이 뭘까요? 서로 다른 두 가지 특징(속성) 사이에 어떤 관련이 있는지 살펴보는 것
한쪽 값이 커질 때 다른 값도 함께 커지면 양(+)의 관계, 반대로 작아지면 음(-)의 관계 예요.
💬 이렇게 질문해요 "공부 시간이 길수록 시험 점수도 높아질까?" 처럼 두 속성을 '~할수록'으로 이어서 묻는 질문이에요.
📌 관계의 3가지 모습
양(+)의 관계
한쪽이 커질 때 다른 값도 함께 커짐 (오른쪽 위로 올라감)
음(-)의 관계
한쪽이 커질 때 다른 값은 작아짐 (오른쪽 아래로 내려감)
관계 없음
한쪽 값이 변해도 다른 값은 규칙 없이 흩어져 있음
🧩 데이터 분석 과정 ①
  • 1. [문제 정하기] 공격력이 높은 포켓몬일수록 방어력도 함께 높을까?
  • 2. [데이터 수집 · 속성 파악] 관계를 살펴볼 두 속성은 '공격력'과 '방어력'이에요.
  • 3. [데이터 분석하기] 아래 순서대로 CODAP 그래프를 그려요.
🖥 CODAP 그래프 그리기

  2. x축에 '공격력' 속성을 클릭해요.
  3. y축에 '방어력' 속성을 클릭해요.
  4. Measure(측정) 클릭 → 최소제곱선 클릭 → Show r 클릭.
  5. 선이 뜬다면 완성이에요.
① 그래프 버튼을 눌러 새 그래프 창 열기
② x축을 클릭해 ③ '공격력' 선택
④ y축을 클릭해 ⑤ '방어력' 선택
⑥ Measure → ⑦ 최소제곱선 → ⑧ Show r (예: r = 0.4996)

📐 용어 최소제곱선 : 흩어져 있는 점들을 대표해서 흐름을 잘 설명해 주는 선.
r (상관계수) : x축과 y축 속성이 서로 얼마나 관련되어 있는지 알려 주는 -1 ~ 1 사이의 수치.
r 값의미
+1 에 가까울수록양의 상관관계 (한쪽이 커질수록 다른 쪽도 커짐)
-1 에 가까울수록음의 상관관계 (한쪽이 커질수록 다른 쪽은 작아짐)
0 에 가까울수록아무 관계가 없음
