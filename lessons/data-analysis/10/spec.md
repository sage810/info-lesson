## 문항 구성 (A형과 달라진 점)
| 번호 | 유형 | B형 | A형과 다른 점 |
|---|---|---|---|
| Q1 | 모두 고르기(3개) | 데이터로 풀 수 있는 문제의 기준 3가지 | A형 Q3 과 같은 문항, 보기 순서를 섞음 (Q1↔Q3 자리 바꿈) |
| Q2 | 하나 고르기 | 데이터 분석 질문으로 가장 적절하지 않은 것 | 보기 소재·정답 위치 다름 |
| Q3 | 순서 | 데이터 분석 과정 순서(a)~(d) | A형 Q1 과 같은 문장, (a)~(d) 이름표를 바꿔 답 순서가 다름 |
| Q4 | 글자 답 3개 | 로블록스 표(8~14위, 5개 속성) | 행·열이 다름 — 속성 개수·셀 주소 |
| Q5 | 분석 유형 5개 | 소재 교체 | 구성 1·비교 2·관계 1·분포 1 |
| Q6 | 글자 답 | 접속자 수에서 혼자 멀리 떨어진 값의 이름(로블록스) | A형 Q8 자리(Q6↔Q8 자리 바꿈), 소재 교체 |
| Q7 | 하나 고르기 | r값 중 ‘함께 커지는’ 관계가 가장 뚜렷한 것 | A형은 ‘작아지는’ |
| Q8 | 하나 고르기 | r(상관계수) 설명 | A형 Q6 자리(자리 바꿈), 최소제곱선 대신 r |
| Q9 | 비교 분석 + 그래프 + 해석 | 분야별 평균 **총조회수** | A형은 평균 구독자 수 |
| Q10 | 관계 분석 + 그래프 + 해석 | **구독자 수 ↔ 총조회수** | A형은 동영상 수 ↔ 구독자 수 |

- 9·10번 데이터: `assets/youtube-top100.csv`(09 와 같은 파일). 4번 표는 `input/roblox_popular_game.csv` 의 8~14위.
- 데이터에서 확인한 값(해석 보기의 근거): 분야별 평균 총조회수 순위, 구독자 수–총조회수 r, 구독자 수–동영상 수 r.
