📊 CODAP 들어가고, 데이터 올리는 법
🖥 CODAP에 데이터 올리기
  1. 구글에 '코답' 이라고 검색해요.
  2. 검색 결과에서 CODAP(codap.concord.org) 사이트를 클릭해요.
  3. 오른쪽 맨 위에 있는 주황색 Launch CODAP 버튼을 눌러요.
  4. 새 문서를 눌러요.
  5. 내려받은 파일을 CODAP의 흰 바탕 위로 끌어다 놓아요.
  6. 화면에 표가 생겼다면 완성! 표의 모서리를 끌어 크기를 키워 데이터가 다 보이게 해요.
① 구글에 '코답' 검색 → ② 검색 결과에서 CODAP 클릭 → ③ Launch CODAP 클릭 → ④ '새 문서' 클릭
파일을 CODAP 흰 바탕으로 끌어다 놓기
표 모서리를 끌어 데이터가 다 보이게 늘리기
📸 캡처해서 붙여넣기
  1. Windows 키 + Shift + S 를 눌러요.
  2. 그래프 부분을 드래그해 네모로 캡처해요.
  3. 시험지의 그래프 칸을 클릭해요.
  4. Ctrl + V 로 붙여넣어요.

안 되면: 캡처한 그림을 파일로 저장하고, 그래프 칸 아래 🖼 파일로 넣기를 눌러요.
