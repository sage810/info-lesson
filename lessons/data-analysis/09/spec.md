## 채점 설계 (2026-10-04 선생님 결정 — A + B 로 만듦)
330명(한 반 30명 × 11개 반)을 USB 로 받던 것을 **구글 시트 자동 제출 + 자동 채점**으로 바꾼다. 정답·허용 답은 여기 적지 않는다(answers.json 의 `_채점_허용답`).

- **흐름**: "PDF로 저장하기" → PDF 는 지금처럼 내려받기(증빙·전송 실패 대비) + 답·PDF·그래프 작은 사본을 Apps Script 로 전송
  → 드라이브 + 시트 "제출" 탭에 한 줄. 저장소의 `apps-script/Code.gs` submit 기능(지금 꺼짐)을 고쳐 쓴다. 계정: **지금 쓰는 계정**.
- **정답 위치**: 시트 "정답" 탭(선생님만)에만. `Code.gs` 는 공개 저장소라 정답을 넣지 않는다.
- **채점**: 시트 메뉴 "채점하기" → "채점" 탭(반별, 학생 한 줄, **마지막 제출**만, 문항별 O/X, 자동 점수, 그래프 점수 입력 칸, 총점) + "문항 분석"(정답률).
- **그래프 모아보기**: 반을 고르면 9-(2)·10-(2) 그래프 30명을 이름과 한 화면에 → 점수 고르면 시트에 들어감.
- **배점 26점**: 미션 1 = Q1·Q2·Q3·Q6·Q7·Q8 각 1 + Q4 소문항 3 × 1 + Q5 소문항 5 × 1 = 14점.
  미션 2 = 9·10 의 (1)(2)(3) **소문항당 2점** = 12점(그래프 9-(2)·10-(2) 4점은 직접 채점). 자동 22 + 직접 4.
  **부분 점수 없음**: Q1(순서 전부 맞아야), Q3(3개 전부 맞아야).
- **짧은 답(4-(1~3)·8)**: 앞뒤 공백 무시, **대소문자 무시**(셀 주소 b2 = B2). 허용 답 목록은 answers.json.
- **학생 확인**: 필수는 **이름만**, 반별 링크 안 씀. 시트에서 반·번호가 빈 줄과 같은 이름을 색칠해 선생님이 확인.
- **같은 학생 여러 번 제출**: 마지막 제출로 채점(학년·반·번호·이름이 같은 것끼리. 반·번호가 비면 이름으로).
- **동시 제출**(수업 끝 30명): 실패하면 자동 재시도, 그래도 안 되면 "다시 보내기" 버튼. PDF 는 이미 내려받아져 있음.
- **가짜 제출**: 신경 쓰지 않음(선생님 결정).
- **A + B 같이**(선생님 결정): 자동 제출(A)이 기본, 같은 기록을 PDF 문서 정보(Keywords, msi-answers:v1)에도 넣어 실패한 학생은 USB PDF 에서 꺼내 같은 길로 보냄(B, npm run exam-pdf). 채점은 시트 한 곳에서만.
- **만든 것**: 시험지 window.MSI_SUBMIT(기록·상태 줄·다시 보내기) · msi-hook(기록 전송) · lesson.json "submit": true(이 차시만) · apps-script/Code.gs(submit 확장·setKey·채점·채점 도우미 페이지) · npm run exam-key · npm run exam-pdf.
- **쓰는 법**: apps-script/README.md "수행평가 자동 제출·채점". 시험 전 선생님이 할 일: Code.gs 새 버전 배포 · TEACHER_KEY · teacher.local.json · exam-key --send · 리허설.
