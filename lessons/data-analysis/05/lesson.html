오늘의 목표
1 데이터 시각화가 무엇인지, 왜 필요한지 설명할 수 있어요.
2 데이터 시각화의 4가지 유형(구성·비교·분포·관계 분석)을 구분할 수 있어요.

MISSION_1 CONCEPT
🎬
데이터 분석하기 — 데이터 시각화란 무엇일까?
🧭 데이터 과학이 문제를 해결하는 과정 4단계
1문제 정하기
→
2데이터 수집 · 특성 파악
→
3데이터 분석하기
→
4결과 해석 · 공유

데이터를 분석할 때는, 복잡한 데이터들을 로 바꾸어 한눈에 볼 수 있도록 만들어요. 이것을 라고 해요.

📋 데이터 시각화가 필요한 이유 데이터를 더 쉽게 이해하고, 데이터 속에 숨겨진 과 를 명확하게 파악하여 의사 결정과 분석을 효과적으로 도울 수 있어요. 같은 데이터를 로 시각화하여 에서 바라보면 새로운 패턴이나 결과를 찾을 수 있어요.
📌 데이터 시각화의 4가지 유형

에 따라 4가지 유형으로 나누어서 그래프를 그려요.

유형의미질문 예시 문형
분석"~는 몇 %일까?"
분석"~과 ~ 중 어느 쪽이 더 클까?"
분석"~는 주로 어디에 몰려 있을까?"
"혼자 특이하게 다른 값이 있을까?"
분석"~가 높을수록 ~도 높을까?"
⚠️ 꼭 기억하세요! 질문 속에 "몇 %", "어느 쪽이 더", "몰려있다/이상치", "~할수록" 같은 표현이 있는지 보면 어떤 분석을 해야 할지 힌트를 얻을 수 있어요.
🖥 CODAP에 데이터 올리기
  1. 구글에 '코답' 이라고 검색해요.
  2. 검색 결과에서 CODAP(codap.concord.org) 사이트를 클릭해요.
  3. 오른쪽 맨 위에 있는 주황색 Launch CODAP 버튼을 눌러요.
  4. 새 문서를 눌러요.
  5. 수업자료 폴더에 있는 포켓몬 파일을 CODAP의 흰 바탕 위로 끌어다 놓아요.
  6. 화면에 표가 생겼다면 완성! 표의 모서리를 끌어 크기를 키워 데이터가 다 보이게 하고, 친구를 도와주세요.
① 구글에 '코답' 검색 → ② 검색 결과에서 CODAP 클릭 → ③ Launch CODAP 클릭 → ④ '새 문서' 클릭
포켓몬 파일을 CODAP 흰 바탕으로 끌어다 놓기
표 모서리를 끌어 데이터가 다 보이게 늘리기
MISSION_2 COMPOSE
🎬
구성 분석
📋 구성 분석이 뭘까요? 피자 한 판을 으로 나누는 것처럼, 전체를 몇 개의 그룹으로 나누고 를 차지하는지 살펴보는 것
💬 이렇게 질문해요 "우리 반 친구들이 좋아하는 계절은 봄·여름·가을·겨울 각각 몇 %일까?" 처럼 '몇 %'를 묻는 질문이에요.
🧩 데이터 분석 과정
  • 1. [문제 정하기]
  • 2. [데이터 수집 · 속성 파악] 포켓몬 표에는 · · · · · · 속성이 있어요.
  • 3. [데이터 분석하기] 아래 순서대로 CODAP 그래프를 그려요.
🖥 CODAP 그래프 그리기
  1. 그래프 버튼을 눌러 새 그래프 창을 열어요.
  2. x축에 '타입' 속성을 클릭해요. (y축은 비워 두기)
  3. Measure(측정)를 클릭하고 백분율을 체크해요.
  4. 위에 각 타입마다 몇 %인지 세어 주는 숫자가 뜬다면 완성이에요.
① 그래프 버튼을 눌러 새 그래프 창 열기
② x축을 클릭해 ③ '타입' 선택 (y축은 비움)
④ Measure → ⑤ 백분율 체크 → 위에 % 표시
✂️ 그래프를 캡처해서 붙여넣는 방법
WIN + SHIFT + S
1윈도우키 + Shift + S 를 함께 눌러요
2캡처할 부분을 마우스로 드래그해요
3아래 칸을 누르고 Ctrl + V 로 붙여넣어요
📷 여기에 CODAP 그래프를 붙여넣으세요
📷 이 칸을 클릭한 뒤 Ctrl + V 로 캡처한 그래프를 붙여넣어요
(그림 파일을 이 칸으로 끌어다 놓아도 돼요 · 지우기: 아래 🗑 버튼 또는 Delete 키)

MISSION_3 COMPARE
🎬
비교 분석
📋 비교 분석이 뭘까요? 서로 다른 그룹의 크기(평균, 합계 등)를 나란히 놓고 살펴보는 것
💬 이렇게 질문해요 "우리 반과 옆 반의 평균 키는 어느 쪽이 더 클까?" 처럼 두 그룹을 콕 집어 '더 큰지 / 작은지'를 묻는 질문이에요.
🧩 데이터 분석 과정
  • 1. [문제 정하기]
  • 2. [데이터 수집 · 속성 파악] 비교할 그룹은 '', 비교할 값은 ''이에요.
  • 3. [데이터 분석하기] 아래 순서대로 CODAP 그래프를 그려요.
🖥 CODAP 그래프 그리기
  1. 그래프 버튼을 눌러 새 그래프 창을 열어요.
  2. x축에 '타입' 속성을 클릭해요.
  3. y축에 '공격력' 속성을 클릭해요.
  4. Measure(측정)를 클릭하고 Mean을 체크해요. (Mean : 평균을 의미)
  5. 각 타입마다 평균 공격력을 나타내는 파란 선이 뜬다면 완성이에요.
① 그래프 버튼을 눌러 새 그래프 창 열기
② x축을 클릭해 ③ '타입' 선택
④ y축을 클릭해 ⑤ '공격력' 선택 (x축은 '타입')
⑥ Measure → ⑦ Mean 체크 → 타입마다 평균 파란 선

유형의미질문 예시 문형
