`ai/exam-entry` 만 받는 **새 Apps Script · 새 시트**. 인공지능 A·B형(`apps-script-ai-exam/`)·09·10(`apps-script/`)과 따로 움직인다.
시트에 **수식이 하나도 없다** — 점수·총점·보정 총점은 이 코드가 숫자로 쓰고, PDF·캡처는 링크 글자로 넣는다.

## 시트 「인공지능 엔트리 수행평가 채점」 — 탭 5개

| 탭 | 내용 |
|---|---|

| 채점 | 학생 한 줄 · 학년 반 번호 이름 · **총점 · 보정 총점** · 칸별 점수(결과 화면 · 1 · 2 · 3 · 4 · 5) · 저장 시각 · 출처 · PDF · 캡처 · 확인 |

- **3·4번은 제출할 때 자동 채점**. **1·2번·결과 화면은 Claude 가 자동 채점해 흐린 점수로 넣는다**(2026-11-17). 선생님이 채점 도우미에서 결과 화면 캡처와 글을 보고 점수를 눌러 확정한다(아래 「자동 채점(Claude)」).
- **5번 엔트리 과제 제출은 학생 답이 없다** — 시험지가 알 수 없어서, 선생님이 엔트리 학급에서 확인하고 도우미에서 0·1·2점을 누른다. 총점은 12점(자동 4 + 직접 8)이다.
- 같은 학생(학년·반·번호·이름)은 한 줄. 다시 내면 자동 점수는 새 답으로 다시 매기고, 직접 점수는 남긴 채 **확인** 칸에 「다시 냄 — 점수 확인」을 띄운다.
- 보정 총점 = 총점 + n, x 보다 작으면 x, y 보다 크면 y(x·y 는 비우면 안 씀). 채점 도우미 위쪽 칸에서 바꾸고 「적용」.
- 파일은 드라이브 「인공지능 엔트리 수행평가 제출」 › `PDF`·`캡처` 폴더.

## 처음 올리기 (한 번)

1. https://script.google.com → **새 프로젝트** → 이름 「인공지능 엔트리 수행평가 API」.
2. 왼쪽 ⚙ **프로젝트 설정** → 「편집기에서 appsscript.json 매니페스트 파일 표시」 체크.
3. 편집기에서 `Code.gs` 내용을 모두 지우고 이 폴더의 `Code.gs` 를 붙여넣기 · `appsscript.json` 도 이 폴더 것으로 바꾸기 → 💾 저장.
4. ⚙ 프로젝트 설정 → **스크립트 속성** → 속성 추가: `TEACHER_KEY` = 이 폴더 `teacher.local.json` 의 `teacherKey` 값(A·B형 프로젝트와 같은 값으로 만들어 둠).
5. 편집기 위 함수 목록에서 **`setup`** 고르고 ▶ 실행 → 권한 허용(고급 → 이동) → 실행 로그에 폴더·시트 주소가 나온다.
6. 오른쪽 위 **배포 → 새 배포** → 유형 ⚙ **웹 앱** → 실행: **나** · 액세스: **모든 사용자** → 배포 → **웹 앱 URL 복사**.
7. 이 PC 에서 `lessons/ai/exam-entry/lesson.json` 의 `"apiUrl": ""` 에 그 URL 을 넣는다(Claude 에게 「주소 넣어줘」 해도 됨).
8. 정답·채점 기준 보내기: `npm run exam-key -- ai/exam-entry --send` → 「설정」 탭에 칸·배점·정답·기준.
9. 채점 도우미: `<웹 앱 URL>?action=teacher&key=<TEACHER_KEY>` (북마크).

`apiUrl` 이 비어 있으면 시험지가 아무 데도 보내지 않는다. 넣은 뒤 `npm run build`.

## 자동 채점(Claude) — 선생님 지시 2026-11-17

학생이 PDF 로 내면 **1분 안에** Claude 가 **글 칸(1·2번)과 결과 화면 캡처** 을 채점해 시트와 채점 도우미에 **흐린 점수**로 넣는다.
선생님이 도우미에서 그 점수(또는 다른 점수)를 **눌러야 진한 점수로 확정**된다.

- 흐린 점수도 총점·결과에 **더해진다**. 확정 전인 학생은 「확인」 칸에 `자동 n칸 미확인` 이 뜬다. 시트에서는 회색 글자.
- 도우미 카드에는 `🤖 자동 채점 n점 — 이유` 가 보인다. 맞으면 흐린 버튼을 그대로 누르고, 아니면 다른 점수를 누른다.
- 확정한 칸은 학생이 다시 내도 자동으로 바꾸지 않는다. 대신 「다시 냄 — 점수 확인」이 뜬다. 확정 전인 칸은 새 답으로 다시 채점한다.
- 안 쓴 칸은 Claude 에 보내지 않고 0점(흐림)으로 넣는다.
- 3·4번(고르기)은 예전처럼 제출할 때 정답과 비교해 바로 채점한다.
- **5번(엔트리 과제)**은 학생 답이 없어서 직접 채점한다.
- **캡처 사본이 없는 학생**(PDF 로 들어온 학생)의 결과 화면은 자동 채점하지 않는다. PDF 를 보고 직접 채점한다.
- Claude 에는 **문제 글 · 채점 기준 · 예시 답 · 학생 답**만 간다. 이름·학번은 보내지 않는다. 학생 글은 Anthropic 서버에서 처리된다.
- 실패하면 1분마다 다시 한다. 같은 제출이 3번 실패하면 멈추고 「자동 채점 실패」가 뜬다. 그 학생은 직접 채점한다.
- 도우미 **🤖 지금 자동 채점** 버튼을 누르면 기다리는 학생을 바로 채점한다. 이 버튼은 트리거가 없으면 트리거도 만든다.

켜기(한 번):
1. https://console.anthropic.com → API Keys 에서 키를 만든다(결제 수단 필요). 비용은 학생 한 명에 대략 50~150원이다(Opus 5.5 기준 — 100만 토큰당 입력 $4·출력 $20). 실제 비용은 콘솔 Usage 에서 본다.
2. 스크립트 속성 **`CLAUDE_API_KEY`** 에 그 키를 넣는다. **키는 이 저장소·채팅·시트에 적지 않는다.**
3. 선택 속성:
   - `CLAUDE_MODEL`: 기본 `claude-opus-5-5`.
   - `CLAUDE_EFFORT`: 기본 `low`. `medium` 으로 올리면 더 꼼꼼하지만 느리고 비싸다.
4. 새 Code.gs 를 올린 뒤 **`setup` ▶ 한 번 더 실행**한다. 「외부 서비스 연결」 권한 허용 창이 다시 뜨고, 1분마다 도는 트리거 「자동채점」이 생긴다.
5. `npm run exam-key -- <차시> --send` 를 **다시** 한다. 설정 탭에 「예시 답」·「문제(자동 채점용)」 열이 새로 채워진다.

키가 없으면 자동 채점은 꺼져 있다. 그래도 예전처럼 직접 채점할 수 있다.
