# 인공지능 엔트리 수행평가 전용 Apps Script (2026-11-07)

`ai/exam-entry` 만 받는 **새 Apps Script · 새 시트**. 인공지능 A·B형(`apps-script-ai-exam/`)·09·10(`apps-script/`)과 따로 움직인다.
시트에 **수식이 하나도 없다** — 점수·총점·보정 총점은 이 코드가 숫자로 쓰고, PDF·캡처는 링크 글자로 넣는다.

## 시트 「인공지능 엔트리 수행평가 채점」 — 탭 4개

| 탭 | 내용 |
|---|---|
| 제출 | 학생이 낸 기록 원본(낼 때마다 한 줄) · PDF 링크 · 캡처 파일 · 답(JSON) |
| 채점 | 학생 한 줄 · 학년 반 번호 이름 · **총점 · 보정 총점** · 칸별 점수(1 · 2 · 3 · 4) · 저장 시각 · 출처 · PDF · 캡처 · 확인 |
| 결과 | 학년 · 반 · 번호 · 이름 · 총점 · 보정 총점 — 학년 → 반 → 번호 순. 점수·보정·제출이 바뀔 때마다 자동으로 다시 씀(손으로 고치면 지워짐) |
| 설정 | 보정 값 n(더할 점수)·x(최저)·y(최고) · 칸·배점·정답·채점 기준(`npm run exam-key` 가 보냄) |

- **3·4번은 제출할 때 자동 채점**, **1·2번·결과 화면은 채점 도우미에서 직접**(결과 화면 캡처를 함께 띄워 0·1·2점을 누른다).
- **5번 엔트리 과제 제출은 학생 답이 없다** — 시험지가 알 수 없어서, 선생님이 엔트리 학급에서 확인하고 도우미에서 0·1·2점을 누른다. 총점은 12점(자동 4 + 직접 8)이다.
- 같은 학생(학년·반·번호·이름)은 한 줄. 다시 내면 자동 점수는 새 답으로 다시 매기고, 직접 점수는 남긴 채 **확인** 칸에 「다시 냄 — 점수 확인」을 띄운다.
- 보정 총점 = 총점 + n, x 보다 작으면 x, y 보다 크면 y(x·y 는 비우면 안 씀). 채점 도우미 위쪽 칸에서 바꾸고 「적용」.
- 파일은 드라이브 「인공지능 엔트리 수행평가 제출」 › `PDF`·`캡처` 폴더.

## 처음 올리기 (한 번)

1. https://script.google.com → **새 프로젝트** → 이름 「인공지능 엔트리 수행평가 API」.
2. 왼쪽 ⚙ **프로젝트 설정** → 「편집기에서 appsscript.json 매니페스트 파일 표시」 체크.
3. 편집기에서 `Code.gs` 내용을 모두 지우고 이 폴더의 `Code.gs` 를 붙여넣기 · `appsscript.json` 도 이 폴더 것으로 바꾸기 → 💾 저장.
4. ⚙ 프로젝트 설정 → **스크립트 속성** → 속성 추가: `TEACHER_KEY` = 이 폴더 `teacher.local.json` 의 `teacherKey` 값(A·B형 프로젝트와 같은 값으로 만들어 둠).
5. 편집기 위 함수 목록에서 **`setup`** 고르고 ▶ 실행 → 권한 허용(고급 → 이동) → 실행 로그에 폴더·시트 주소가 나온다.
6. 오른쪽 위 **배포 → 새 배포** → 유형 ⚙ **웹 앱** → 실행: **나** · 액세스: **모든 사용자** → 배포 → **웹 앱 URL 복사**.
7. 이 PC 에서 `lessons/ai/exam-entry/lesson.json` 의 `"apiUrl": ""` 에 그 URL 을 넣는다(Claude 에게 「주소 넣어줘」 해도 됨).
8. 정답·채점 기준 보내기: `npm run exam-key -- ai/exam-entry --send` → 「설정」 탭에 칸·배점·정답·기준.
9. 채점 도우미: `<웹 앱 URL>?action=teacher&key=<TEACHER_KEY>` (북마크).

`apiUrl` 이 비어 있으면 시험지가 아무 데도 보내지 않는다. 넣은 뒤 `npm run build`.

## Code.gs 를 고쳤을 때

배포 → **배포 관리** → ✏ 편집 → 버전 **새 버전** → 배포. (「새 배포」를 누르면 주소가 바뀐다.)
