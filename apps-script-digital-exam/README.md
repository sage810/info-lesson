# 디지털 문화 수행평가 전용 Apps Script (2026-11-17)

`digital-culture/exam-a`(A형)·`exam-b`(B형)를 받는 **새 Apps Script · 새 시트**. `apps-script-ai-exam/`(인공지능 A형·B형)을 복사해
시험 이름·시트 이름·형 목록·「생기부 참고」 칸만 바꿨다 — 동작(제출·채점 도우미·보정·잠금)은 같다.
시트에 **수식이 하나도 없다** — 점수·총점·보정 총점은 이 코드가 숫자로 쓰고, PDF 는 링크 글자로 넣는다.

- 같은 학생(학년·반·번호·이름)은 한 줄. 다시 내면 점수는 남고 **확인** 칸에 「다시 냄 — 점수 확인」.
- PDF 는 드라이브 「디지털 문화 수행평가 제출」 › `A형`·`B형` 폴더.
- 형을 더하면 `Code.gs` 의 `FORMS` 에 한 줄 + 도우미 `<select>` 에 option 한 줄.

## 처음 올리기 (한 번)

1. https://script.google.com → **새 프로젝트** → 이름 「디지털 문화 수행평가 API」.
2. 왼쪽 ⚙ **프로젝트 설정** → 「편집기에서 appsscript.json 매니페스트 파일 표시」 체크.
3. 편집기에서 `Code.gs` 내용을 모두 지우고 이 폴더의 `Code.gs` 를 붙여넣기 · `appsscript.json` 도 이 폴더 것으로 바꾸기 → 💾 저장.
4. ⚙ 프로젝트 설정 → **스크립트 속성** → `TEACHER_KEY` = `teacher.local.json` 의 `teacherKey` 값(인공지능 시트와 같은 값).
5. 함수 목록에서 **`setup`** ▶ 실행 → 권한 허용(고급 → 이동) → 실행 로그에 폴더·시트 주소.
6. **배포 → 새 배포** → ⚙ **웹 앱** → 실행: **나** · 액세스: **모든 사용자** → 배포 → **웹 앱 URL 복사**.
7. `lessons/digital-culture/exam-a/lesson.json`·`exam-b/lesson.json` 의 `"apiUrl": ""` 에 그 URL(Claude 에게 「주소 넣어줘」 해도 됨) → `npm run build`.
8. `npm run exam-key -- digital-culture/exam-a --send` · `npm run exam-key -- digital-culture/exam-b --send` → 「설정」 탭에 칸·배점·기준.
9. 채점 도우미: `<웹 앱 URL>?action=teacher&key=<TEACHER_KEY>` (북마크).

이 PC 의 clasp(학교 계정)로도 올릴 수 있다 — `clasp create --type webapp --title "디지털 문화 수행평가 API"` → 이 폴더 파일 넣고 `clasp push` →
편집기에서 `setup` ▶ 한 번(권한 허용은 사람이) → `clasp create-version` → `clasp deploy`. 고칠 때는 `apps-script-ai-exam/README.md` 「Code.gs 를 고쳤을 때」와 같다.

`apiUrl` 이 비어 있으면 시험지가 아무 데도 보내지 않는다. 시험해 볼 땐 실제 주소로 보내지 말고 가로채서(page.route) 하거나, 리허설은 반을 99 처럼 없는 반으로.


## 자동 채점(Claude) — 선생님 지시 2026-11-17

학생이 PDF 로 내면 **1분 안에** Claude 가 **모든 칸(1-1 · 1-2 · 2 · 3)** 을 채점해 시트와 채점 도우미에 **흐린 점수**로 넣는다.
선생님이 도우미에서 그 점수(또는 다른 점수)를 **눌러야 진한 점수로 확정**된다.

- 흐린 점수도 총점·결과·평균·생기부 참고에 **더해진다**. 확정 전인 학생은 「확인」 칸에 `자동 n칸 미확인` 이 뜬다. 시트에서는 회색 글자.
- 도우미 카드에는 `🤖 자동 채점 n점 — 이유` 가 보인다. 맞으면 흐린 버튼을 그대로 누르고, 아니면 다른 점수를 누른다.
- 확정한 칸은 학생이 다시 내도 자동으로 바꾸지 않는다. 대신 「다시 냄 — 점수 확인」이 뜬다. 확정 전인 칸은 새 답으로 다시 채점한다.
- 안 쓴 칸은 Claude 에 보내지 않고 0점(흐림)으로 넣는다.
- Claude 에는 **문제 글 · 채점 기준 · 예시 답 · 학생 답**만 간다. 이름·학번은 보내지 않는다. 학생 글은 Anthropic 서버에서 처리된다.
- 실패하면 1분마다 다시 한다. 같은 제출이 3번 실패하면 멈추고 「자동 채점 실패」가 뜬다. 그 학생은 직접 채점한다.
- 도우미 **🤖 지금 자동 채점** 버튼을 누르면 기다리는 학생을 바로 채점한다. 이 버튼은 트리거가 없으면 트리거도 만든다.

켜기(한 번):
1. https://console.anthropic.com → API Keys 에서 키를 만든다(결제 수단 필요). 비용은 학생 한 명에 대략 50~150원이다(Opus 5.5 기준 — 100만 토큰당 입력 $4·출력 $20). 실제 비용은 콘솔 Usage 에서 본다.
2. 스크립트 속성 **`CLAUDE_API_KEY`** 에 그 키를 넣는다. **키는 이 저장소·채팅·시트에 적지 않는다.**
3. 선택 속성:
   - `CLAUDE_MODEL`: 기본 `claude-opus-5-5`.
   - `CLAUDE_EFFORT`: 기본 `low`. `medium` 으로 올리면 더 꼼꼼하지만 느리고 비싸다.
4. 새 Code.gs 를 올린 뒤 **`setup` ▶ 한 번 더 실행**한다. 「외부 서비스 연결」 권한 허용 창이 다시 뜨고, 1분마다 도는 트리거 「자동채점」이 생긴다.
5. `npm run exam-key -- <차시> --send` 를 **다시** 한다. 설정 탭에 「예시 답」·「문제(자동 채점용)」 열이 새로 채워진다.

키가 없으면 자동 채점은 꺼져 있다. 그래도 예전처럼 직접 채점할 수 있다.
