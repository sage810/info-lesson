# 피드백 모드 (수정 요청 메모)

활동지 화면에서 **고칠 곳을 직접 가리켜 요청을 남기면** Claude 가 그 요청대로 `lesson.html` 을 고치는 기능.
정보부 업무 관리 앱의 "피드백 모드"를 이 저장소 구조(Vite 없음, `dist/pages` 미리보기)에 맞게 다시 만든 것이다.

- 선생님 전용. 켜지 않으면 아무것도 하지 않아서 학생 화면에는 보이지 않는다.
- 이 PC 미리보기에서는 요청이 `.claude/feedback.md` 에 바로 쌓인다. GitHub Pages 에서는 복사·붙여넣기로 보낸다.

## 1. 켜기

| 방법 | 하는 일 |
|---|---|
| Claude 에게 **"피드백 모드"** 또는 **"메모 켜줘"** | 아래 `npm run memo` 를 대신 실행 |
| 차시를 함께 말하기: "03차시 피드백 모드" | 그 차시를 연다 (안 말하면 `lesson.html` 을 가장 최근에 고친 차시) |
| 터미널: `npm run memo -- 03` | 빌드 → 미리보기 서버(8080)가 꺼져 있으면 뒤에서 켬 → `http://127.0.0.1:8080/<단원>/<차시>/?memo=1` 을 브라우저로 연다 |

- 끄기: 주소 끝을 `?memo=0` 으로 바꿔 연다. 서버는 끌 필요 없다.
- 한 번 `?memo=1` 로 열면 그 브라우저가 기억해서 다른 차시에서도 켜져 있다.

## 2. 쓰는 법

1. 오른쪽 아래 **📝 메모** 를 누른다.
2. 고칠 곳을 고른다 (둘 중 하나, 안 골라도 된다).
   - **🎯 요소 고르기** → 마우스를 올린 곳에 분홍 점선 테두리 → 클릭. 고르는 동안 활동지 버튼·탭은 반응하지 않는다. **Esc** 로 취소.
   - 글을 **드래그**해서 선택 (빈칸 안 글도 된다).
3. 어떻게 고칠지 적고 **📤 보내기** → `.claude/feedback.md` 에 쌓인다.
4. 창 안 목록에 이 차시에서 아직 처리 전인 요청이 보인다. **✕** 로 지울 수 있다(처리된 것은 안 보임).
5. 여러 곳을 돌아다니며 계속 보낸 뒤, Claude 에게 **"피드백 처리해줘"** (또는 `/feedback_mode`).

GitHub Pages 주소에서 켜면 "📤 보내기" 대신 **➕ 목록에 담기 → 📋 전체 복사 → Claude 대화에 붙여넣기** 다.
이 목록은 그 브라우저에만 있다(localStorage).

## 3. 기록 형식 (`.claude/feedback.md`)

```
## 2026. 10. 2. 19시 58분 25초 · data-analysis/03 「데이터 과학」
- 종류: 메모
- 요소: div.tab-chip › span          ← 🎯 요소 고르기로 골랐을 때
- 위치: 이용 규칙 (칸: 화면 고르기)   ← 탭 › MISSION_n › 가장 가까운 소제목 (칸: aria-label)
- 선택한 글: "시간표"
- 메모: 탭 글자를 더 크게
- 화면: 정보 수업 활동지 · 1280×860
- 상태: [ ] 처리 전
```

- 처리하면 `- 상태: [x] 처리됨 — 무엇을 어느 파일에서 했는지 한 줄`.
- 이 파일은 `.gitignore` 에 있다. 저장소가 공개라서 시험지 관련 요청이 섞여도 올라가지 않게 한다.
- 요소 이름은 클래스가 없으면 클래스 있는 가장 가까운 부모를 앞에 붙인다. 활동지 본문은 인라인 스타일이 많아
  `div#appPage › div` 처럼 약하게 나오므로, 찾을 때는 **선택한 글·위치**가 주 단서다.

## 4. Claude 가 처리하는 순서

1. `.claude/feedback.md` 의 `[ ]` 항목을 읽는다. 세션을 시작할 때 `[ ]` 가 있으면 먼저 알린다.
2. `lessons/<단원>/<차시>/lesson.html` 에서 **선택한 글의 짧은 조각**을 Grep 한다(태그로 쪼개져 있을 수 있어 앞·뒤 한 토막씩). 위치·칸 이름·요소 이름을 보조로 쓴다.
3. `lesson-edit` 규칙대로 **요청한 범위만 최소 diff** 로 고친다. 모호하거나 정답·진행률·정답지에 영향이 있으면 고치기 전에 묻고 `[ ]` 로 둔다.
4. "밋밋해", "더 보기 좋게"처럼 느낌·판단인 요청은 바로 고치지 않고 후보 2~3개를 먼저 보인다. 기준은 `docs/rules/design.md` 토큰.
5. `npm run check -- <차시>` + 캡처로 확인하고, 항목을 `[x]` + 한 줄로 닫는다. 정답이 바뀌었으면 `answers.json` 도 맞춘다.
6. 항목별로 고친 것·못 고친 것을 짧게 알린다.

## 5. 구성 파일

| 파일 | 역할 |
|---|---|
| `shared/runtime/msi-memo.js` | 화면 쪽. `?memo=1` 일 때만 켜짐. 요소 고르기·글 선택·위치 찾기·보내기/복사. GitHub Pages 배포본(pages)에만 붙고 구글 사이트용(embed)·정답지 PDF 에는 안 들어간다(`scripts/lib/render.mjs`) |
| `scripts/serve.mjs` | 미리보기 서버. `/__feedback` — GET 처리 전 목록(`?lesson=` 차시별) · POST 추가 · DELETE 처리 전 항목 지우기. 다른 웹사이트가 글을 끼워 넣지 못하게 주소는 127.0.0.1·localhost 만, Origin 은 같은 곳만, 쓰기는 JSON 만 받는다(아니면 403·415) |
| `scripts/memo.mjs` | `npm run memo` — 빌드·서버 켜기·브라우저 열기. 켜진 서버가 옛 버전이면 알림 |
| `scripts/lib/common.mjs` | `serveStatic(dir, port, handle)` — `handle` 이 true 를 돌려주면 파일 대신 응답 |

화면은 `127.0.0.1`·`localhost` 에서 열렸을 때만 `/__feedback` 을 찾아보고, 응답이 있으면 "📤 보내기"로 바뀐다. 없으면 복사 방식 그대로다.

## 6. 문제 해결

| 증상 | 확인 |
|---|---|
| 📝 메모 버튼이 없다 | 주소 끝에 `?memo=1` 이 있는지. 구글 사이트에 붙인 화면(embed)에는 원래 없다 |
| "📤 보내기" 대신 "목록에 담기"가 보인다 | GitHub Pages 주소이거나, 8080 서버가 옛 버전. 서버(node)를 끄고 다시 `npm run memo` (memo 가 △ 로 알려 준다) |
| 보내기를 눌렀는데 "보내지 못했어요" | 미리보기 서버가 꺼졌다. `npm run memo` 로 다시 켠다 |
| 고친 내용이 화면에 안 보인다 | 미리보기는 `dist/pages` 라서 빌드가 필요하다. `npm run memo` 를 다시 하면 빌드부터 한다 |
| 요소 고르기 중에 활동지가 안 눌린다 | 정상. Esc 로 끄거나 한 번 클릭해 고르면 풀린다 |

## 7. 정보부 피드백 모드와 다른 점

- 미리보기 서버(`scripts/serve.mjs`)가 받는다. Vite 플러그인을 쓰지 않는다.
- 글을 드래그해서 고를 수도 있고, 위치를 탭 › MISSION › 소제목으로 적는다. CSS 전체 경로는 적지 않는다.
- 글자를 화면에서 미리 고쳐 보기, "디자인 추천 받기" 체크, 보낸 요청 고치기(PUT)는 없다. 느낌·판단인 요청은 체크 없이도 후보를 먼저 보인다.
