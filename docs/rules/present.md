# 수업용 슬라이드(수업용 화면) 규칙

선생님이 교실 화면에 띄워 개념을 설명하고 **빈칸 정답을 하나씩 공개**하는 한 장짜리 HTML.
본보기: `lessons/ai/01/present.html`(「인공지능이란?」, 2026-10-19 처음 만듦 · 이력 `docs/log/activity.md`).

## 1. 파일 하나만 두면 나머지는 빌드가 한다

- 차시 폴더에 **`present.html`** 을 둔다 → `npm run build` 가
  1. `dist/pages/<단원>/<차시>/present.html` 로 같이 올리고(`scripts/build.mjs` · `renderPage` — `msi-asset:` 표식만 바꿈, 제출 스크립트 없음),
  2. **사이트 첫 화면의 그 차시 줄에 `학생용 · 교사용 · 수업용 슬라이드` 버튼**을 붙인다(`scripts/lib/index-page.mjs`, 선생님 지시 2026-10-20).
     `present.html` 이 없는 차시에는 버튼이 생기지 않는다 — 첫 화면은 손으로 고치지 않는다.
- 주소: `https://sage810.github.io/info-lesson/<단원>/<차시>/present.html` · 이 PC `http://127.0.0.1:8080/<단원>/<차시>/present.html`
- 메모(피드백 모드)도 된다: `…/present.html?memo=1` (`#n` 을 붙이면 n번째 장부터 열림).

## 2. 새 차시에 만들 때

1. `lessons/ai/01/present.html` 을 새 차시 폴더로 복사하고 `<title>`(「<차시 제목> 수업용 화면」)과 `<section class="slide">` 장들만 바꾼다.
   머리의 `<meta name="robots" content="noindex">`, `<style id="msi-role-tokens">` 블록(자동 생성), 글꼴 `msi-asset:shared/fonts/…`, 아래 스크립트는 그대로 둔다.
2. 장은 활동지(`lesson.html`) 순서대로: 표지 → 내 정보 적기 → 사용 안내 → 도입 → 활동 1… → 정리 → 형성평가.
   활동지 단계 하나 = 장 하나가 기본이고, 설명을 돕는 장(영상 · 비유 · 그림)은 그 단계 바로 앞뒤에 끼운다 — 모양은 §6.
   장마다 `data-role`(색 역할) · `data-phase`(도입/전개/정리) · `data-code`(ACTIVITY_1 …) · `data-badge` · `data-title`(카드 제목) · `data-name`(장 이름)을 적는다.
3. 공개 부품(정답 가림 → 누르거나 Space 로 하나씩 열림): 글자 빈칸 `.qb` · 이름표 칸 `.lm-s`(+ 위 `.tray` 이름표) · 하나 고르기 `.pick` · O/X `.oxq` · 열 하나씩 `.colrv`.
   이름표 색은 같은 낱말이면 어느 장에서나 같게 — 머리 CSS 의 `[data-v="…"]{--cat:…}` 줄.
4. 색은 역할 토큰 `var(--msi-role-…)` 만. 그림·영상은 `assets/` + `msi-asset:./assets/…`.
5. 무대는 1600×900 고정(창 크기에 맞춰 줄였다 늘림, 스크롤 없음) — 한 장에 넘치면 두 장으로 나눈다.

## 3. 활동지를 고치면 수업용 화면도 맞춘다

활동지에서 활동·표 줄·이름표·O/X 를 빼거나 더하면 `present.html` 의 같은 장도 같이 고친다(2026-10-20 ai/01 활동 4 삭제·되살림 때처럼).
빠진 장에만 쓰던 CSS·이름표 색 줄도 함께 지우고, 장이 비면 남은 내용을 가운데에 크게 둔다.

### 차시 테마 (2026-10-22)
- 수업용 화면은 그 차시 `lesson.json` 의 `"theme"` 을 따른다(빌드가 같은 theme.css 를 넣음). ai/01 = `sticker`.
- 모양은 변수로 쓴다 — 그림자 `var(--msi-shape-shN) rgba(var(--msi-rgb-ink),…)` · 잉크 `rgba(var(--msi-rgb-ink),…)` · 틀과 같은 크기의 테두리 · 모서리 `--msi-shape-bwN` · `rN`.
  ai/01 을 복사하면 이미 그렇다. 새 부품을 더할 때도 숫자 대신 변수로.
- 장 머리 아이콘(`#bBadge`)은 스크립트가 장의 `data-badge` 를 `data-ic` 로도 붙인다 → 테마가 그림으로 바꿀 수 있다. 이 줄을 지우지 않는다.

## 4. 확인

- `npm run build` → 모든 장을 브라우저로 열어 오류·넘침 0, 바뀐 장은 「👀 이 화면 정답 모두 보기」 전후 캡처
  (Playwright 스크립트는 scratchpad 에 — 페이지의 `window.__present.go(i)` · `revealAll(true)` · `count` 를 쓴다).
- 첫 화면(`dist/pages/index.html`)에 그 차시의 「수업용 슬라이드」 버튼이 보이는지.

## 5. ⏱ 타이머 (선생님 결정 2026-10-20)

- 아래 버튼줄 「⛶ 전체화면」 바로 앞 **⏱ 타이머** — 누르면 장 가운데에 타이머 카드, **다시 누르면 멈추고 사라짐**.
- 분 0~30 · 초 10초 단위 드롭다운 → ▶ 시작. 마지막에 고른 값은 이 기기에 기억(`localStorage` `msi-present-timer`).
- 슬라이드는 흐리게 하지 않는다(카드 밖은 그대로 누름) · 장을 넘겨도 계속 흐름 · 스페이스는 그대로 「정답 하나씩」.
- 남은 시간이 1분(짧은 타이머는 전체의 20%) 이하면 노랑 「곧 끝나요」, 끝나면 연어색 「⏰ 시간 끝!」.
- **소리**(선생님 결정 2026-10-21, 파일 없이 만든 소리 — 미리 듣고 고름): 흐르는 동안 매초 「째깍-똑딱」(두 음 번갈아) · 「곧 끝나요」가 되는 순간 「띵」 한 번 · 마지막 10~6초 나무 째깍 · 5~1초 「삐」(같은 높이) · 0초 부저 3번(4초 간격).
  ⏸ 멈춤이면 소리도 멈춤. 흐르는 동안 「🔕 소리 끄기 / 🔔 소리 켜기」, 끝난 뒤 「🔕 소리 끄기」는 부저 멈춤. 30분이면 째깍이 1,800번이라 앞 2초 안의 소리만 예약(`plan()`).
- `present.html` 을 복사하면 타이머도 따라온다(CSS `⏱ 타이머` 묶음 · `#timer` 카드 · 맨 아래 타이머 스크립트). 점검은 `window.__timer`(`open`·`close`·`start(ms)`·`state()`).
- 참고: github.com/sage810/timer — 끝나는 시각으로 계산, 소리는 오디오 시계에 예약, 흐르는 동안 화면 꺼짐 막기.

## 6. 장 모양 — ai/01 피드백 기준 (선생님 2026-10-19~20)

멀리서도 읽히는 것이 먼저다. 아래 부품은 모두 `lessons/ai/01/present.html` 에 CSS 이름 그대로 있다 — 복사해서 쓴다.

### 글자 · 안내
| 규칙 | 모양 | 근거 |
|---|---|---|
| 조작 안내 글은 쓰지 않는다 | 「빈칸에 알맞은 낱말을 적어요.」 「이름표를 끌어다 놓아요.」 같은 `p.sub`, 허용 답 줄(※ …)은 넣지 않는다 — 장 제목이 할 일을 말한다 | 「삭제」 ×5 |
| 설명 글이 중요하면 크게 | `.lead.lead--big` — 36px 굵게, 2~3줄로 끊고 핵심어만 `<b>`(라일락 형광펜) | 「눈에 띄게」 → 시안 B |
| 꼭 지킬 것은 노란 상자 | `.must` — 버터 상자 42px, 줄마다 「⚠️ …」, 숫자·범위는 `<b>`(연어색 형광펜). 예: 데이터 30개까지만 · 4단계까지만 | 「중요하게 보이도록」 |
| 형광펜은 글자에만 | 카드 배경은 흰색 그대로, 강조할 낱말만 `<mark>` · `<b>` 형광펜. 두 번째 색은 **그 장에서 안 쓰인 색** | 「배경색 없애고 형광펜」 |
| 쉬운 말로 | 그 차시에서 선생님이 정한 말로 통일(ai/01: 수업용 화면은 「낙서」 → 「그림」 25군데). 활동지는 따로 정한다 | 10-19 |

### 표 · 문제
| 규칙 | 모양 | 근거 |
|---|---|---|
| 표는 장을 꽉 채워 크게 | `table.tbl.tbl--big.tbl--fill` — 글자 30px, 빈칸 32px. 줄이 6개쯤이면 `.tbl--sum`(28px) | 「표 최대한 크게, 멀리서도」 |
| 한 장에 문제 4개까지 | 이름표 줄이 많으면 4개씩 나눠 장을 늘린다(`(1~4)` · `(5~8)`), `.lm.lm--roomy` 줄 글자 29px | 「한 페이지에 4개만」 |
| 아래 여백을 남기지 않는다 | 줄이 장 높이를 채우게 `.lm--fill`(28px) | 「아래에 여백 남지 않도록」 |
| 두 문제를 한 장에 | `.halves > .half` ×2 — 세로 반씩, 가운데 점선 | 「2번·3번 절반씩」 |
| 내용은 제목 바로 아래 | 화면 가운데가 너무 아래로 보이면 위 정렬(이름표 → 내용) | 「너무 아래」 「조금만 더 위로」 |
| 문제 위에 상황 그림 | 문제 글(`.qcard`) 위에 그 상황을 그린 화면 안 SVG(예: `.mon` 몬스터 9칸 판). 바다 생물 문제처럼 대사가 어울리면 `.say` 🤖 말풍선 | 「관련된 이미지 삽입」 · 「다른 디자인」 |
| 판단 기준은 갈림길 | `.fork` — 「🔍 질문?」 → 예 / 아니요 두 갈래, 답 낱말은 이름표 색 형광펜 | 「텍스트가 너무 작아, 중요」 → 시안 C |

### 정답 공개 색
- 이름표 색은 낱말마다 고정(어느 장에서나 같게): 인공지능 소프트웨어 `#eec6ea`(base-lilac) · 일반 소프트웨어 `#ffd685`(`ui-label-general`) — 선생님 지정 10-19.
- 열린 글자 빈칸·순서 칸은 **칸마다 다른 파스텔**을 차례로(노랑 · 살구 · 라일락 · 연두 · 물빛 · 분홍 — 스크립트의 `ANS` 목록 → `--ans`).
