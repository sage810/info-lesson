# 활동지 순서 — 도입 · 전개 · 정리 (선생님 결정 2026-10-15, 시안 C)

**새로 만드는 수업 활동지**(lesson-new)는 이 순서·모양으로 만든다. 이미 있는 차시(01~07)는 선생님이 따로 말하기 전까지 그대로 둔다.
모양 참고: [`order-preview.html`](order-preview.html)(브라우저로 열기 — 07 로블록스 내용으로 만든 확정안 C).

**색 값의 최신·정답은 [`color-map.md`](color-map.md)**(`design/tokens.json` role 에서 자동 생성) — 아래 절들의 색은 "왜 그렇게 정했나" 이력이다.
새 차시는 틀 `lessons/_templates/order` 에서 출발한다(§3).

## 2. 모양 (시안 C)

- **카드 머리 오른쪽 작은 글자(GOAL·동기유발·COMPOSE 등)는 넣지 않는다** — 머리에는 단계 이름표 + 픽셀 이름만(2026-10-15 피드백).
- **주제 카드**(단원 이름 줄 · 큰 제목)는 **가운데 정렬**.

- **단계 이름표**: 카드 머리 왼쪽, 픽셀 이름 앞에 작은 흰 이름표(2px 잉크 테두리, 둥근 6px, CookieRun 700 12px) — `도입` · `전개` · `정리`.
- **단계 색**(카드 머리 바탕):
  도입 `#fbe6a2`(노랑, `--msi-yellow`) · 전개 `#c4d8f7`(파랑, `--msi-blue`) · 정리 — **핵심 요약 `#e8c4c4`**(로즈 더스트, `--msi-rose-dust`, 카드 바탕 `#fcf5f5`, 표 머리 `#f6e6e6`) · **형성평가 `#eec6ea`**(라일락, `--msi-lilac`, 카드 바탕 `#fdf5fc`)
  — 정리는 활동 카드 색(파랑·노랑·보라·민트)과 겹치지 않게 라일락(2026-10-15 피드백, 민트는 활동 4와 같아 바꿈).
  왼쪽 고정 묶음을 쓰면 머리 색은 **PROGRESS(진행률) 살구 `#ffe0cc`**(`--msi-apricot`) · **HELP(도움말 버튼) 베이지 `#e8d9b8`**(`--msi-beige`) (2026-10-15).
  전개 카드가 많아 구분이 필요하면 활동마다 accent 를 바꿔도 되지만, **단계 이름표는 꼭 단다**.
  활동 카드 색은 **도입(노랑)·학습주제(연두) 색과 겹치지 않게** — 07 예시: 활동 1 파랑 · 활동 2 **라임 소다** `linear-gradient(90deg,#f1f8b8,#d6f0a8)`(바탕 `#fbfdf0`) · 활동 3 보라 · 활동 4 민트.
- 그 밖의 색·글꼴·테두리·그림자는 `docs/rules/design.md` 토큰 그대로(구역 띠·타임라인 선은 쓰지 않는다).

## 2-1. 버튼 상태 (2026-10-15 — 시안 `dist/pages/_preview/button-states.html`·`focus-ring.html`)

**모든 버튼은 오로라 유리 알약**(선생님 지시 2026-10-16 — `DESIGN.md` The Aurora Pill Rule). 예전 "종이 버튼"(네모 + 1px 떠오름)은 새로 만들지 않는다.

- 틀(`lessons/_templates/order`)에 class 가 있다: 일반 버튼 **`glass-pill`**, 고르기 버튼 **`glass-chip`**(`data-s="ok"` 민트 ✓ · `"no"` 연어 ✗), PDF 버튼은 큰 알약(§2-1-1).
- 유리 알약인 것: PDF 저장 · 분석 유형 칩 · 🗑 지우기 · 도움말 카드 "닫기 ✕"(class `glass-pill`) · 새로 만드는 버튼.
- **예외 — 지금 모양 유지(선생님 결정 2026-10-16, 시안 `_preview/pill-all.html`)**: 메뉴 탭 4개 · 일간/주간/월간 보기 버튼 · 급식 ◀ ▶ · 왼쪽 HELP 버튼 · 태블릿 "도움말 · 진행률" 버튼.
  단 차시 테마는 메뉴 탭 모양을 바꿀 수 있다(선생님 결정 2026-10-22 — sticker: 분홍 트랙 안 알약, `docs/rules/theme.md`).

| 상태 | 모양 |
|---|---|
| 기본 | 유리 알약 + 그림자 3px |
| 마우스 올림(hover) | 빛 한 줄이 왼→오로 쓱(1초) + 그림자 4px |
| 누르는 순간(active) | 물방울처럼 `scale(1.04, .9)`(튕기는 곡선 `cubic-bezier(.34,1.56,.64,1)`) |
| 키보드 포커스 | **왼쪽에 ▶ 가 깜박**(1초, 레트로 게임 메뉴) + 그림자 4px 진한 잉크. 분홍 고리는 쓰지 않는다 |
| 처리 중(loading) | PDF 버튼: **흐르는 사선 줄무늬**(#c4cce8/#d6dcf3) + **도는 고리** + "PDF 만드는 중…", `aria-busy="true"`, 다시 눌리지 않음 |
| 끝남 · 맞음 | 민트 유리(`pdf-done` / `chip-ok`) + "✓ 저장했어요" 또는 ✓ — 저장은 3초 뒤 원래대로 |
| 실패 · 틀림 | 연어 유리(`pdf-error` / `chip-no`) + "⚠ 다시 눌러 주세요" 또는 ✗ — 저장은 3초 뒤 원래대로(안내 창도 함께) |
| 못 누름(disabled) | 같은 알약, 흐리게(opacity .6) · 움직임 없음 |

- HELP 카드 버튼·닫기 버튼도 같은 움직임(hover 떠오름·누르면 꾹). 메뉴 탭도 0.08초 transition.
- 고른 메뉴 탭은 색이 옅으니 **아래 잉크 띠**(`inset 0 -4px 0 #4b3b6b`)를 함께 — 색만으로 알리지 않는다.
- 키보드 포커스 ▶ 는 **3번만 깜박**이고 켜진 채로 멈춘다.
- 그림(CODAP 화면 등) 테두리는 `outline: 1px solid oklch(0 0 0 / 0.1)`(색 섞인 테두리 쓰지 않음). 펼침 표시 +/− 는 scale·opacity·blur 교차 전환(0.2초, `cubic-bezier(0.2, 0, 0, 1)`).
- 겹친 모서리: 바깥 둥글기 = 안 둥글기 + 안쪽 여백(예: 둥글기 12·여백 8 인 카드 안 버튼은 4).

- 분석 유형처럼 **고른 칩 모양은 지금 활동지 그대로**(바꾸지 않음, 2026-10-15).
