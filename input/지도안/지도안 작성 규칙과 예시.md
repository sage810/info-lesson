# 수업 지도안 작성 규칙과 예시 (중학교 정보)

## 하는 일

선생님이 차시 자료(활동지 양식 docx · spec.md · 활동지 글 붙여넣기 · 수업 PPT 등)와 지도안 틀을 주면,
틀의 칸마다 들어갈 문장을 쓴다.

## 틀 (기본)

선생님이 다른 틀을 주면 그 틀을 따른다.

```
<도입>
[동기유발]

[학습 주제 제시]


<전개>
[활동 1]

[활동 2]

[활동 3]

[활동 4]
<정리>
```

## 쓰는 순서

1. 자료를 읽고 도입(동기유발·학습 주제) · 전개(활동) · 정리로 나눈다.
2. 자료의 활동 수와 틀의 [활동] 칸 수가 다르면, 쓰기 전에 어떻게 묶거나 나눌지 선택지와 추천안을 보여 주고 물어본다.
3. 칸마다 문장을 쓴다(아래 「문장 규칙」).
4. 결과는 코드 블록(```text)에 담아 한 번에 복사할 수 있게 한다.
5. 코드 블록 아래에, 자료에 없는 내용을 덧붙인 곳이나 판단이 애매했던 곳만 1~2줄로 알린다.

## 문장 규칙

- 줄 머리는 `∙ `(가운데 점 + 띄어쓰기). 한 줄에 한 문장.
- 끝은 「~한다.」 평서문. 주어는 쓰지 않는다.
  - 교사 행동: 제시한다 · 안내한다 · 설명한다 · 보여 준다 · 강조한다
  - 학생 활동: 분류한다 · 배열한다 · 관찰한다 · 기록한다 · 연결한다 · 생각해 본다
  - 두 가지를 한 칸 안에 섞어 쓴다.
- 활동지의 학생용 말투(「~해요」「~봐요」)는 지도안 말투(「~한다」)로 바꾼다.
- 사이트·도구 이름을 구체적으로 쓴다(예: Quick, Draw! · code.org의 '바다를 위한 AI' · Canva).
  사례도 2~4개는 이름을 들어 쓴다(예: 틱톡 추천 피드, 인스타그램 필터, 디데이 앱).
- 활동지의 핵심 낱말을 그대로 쓴다(예: 인공 신경망, 인공지능 모델, 레이블).
- 활동 제목·시간·정답 목록은 넣지 않는다.

### 칸별

| 칸 | 줄 수 | 쓰는 법 |
|---|---|---|
| [동기유발] | 2~3줄 | 흥미를 끄는 활동 → 탐구 질문(`"…"라는 탐구 질문을 제시한다`) → 필요하면 생각 적기·발표 |
| [학습 주제 제시] | 1~2문장 | `∙` 없이 큰따옴표 안에. 질문 하나 + 「~해 봅시다.」 청유형. 두 줄로 나눠도 된다 |
| [활동 n] | 3~4줄 | ① 교사가 개념·기준·방법을 안내·설명 ② 학생 활동(구체적인 도구·사례) ③ 깨닫는 점(「~함을 이해한다/확인한다」). 자료의 순서대로 |
| <정리> | 3~4줄 | 핵심 정리 활동 · 형성평가(어떤 방식인지) · 오늘 배운 것의 의미 강조(「~의 기반을 다진다」) · 제출 또는 차시 예고 |

## 자료 읽을 때 주의

- spec.md 는 아래쪽 「피드백」 절이 위쪽 「카드별 내용」보다 우선이다(최신). 피드백에서 지운 단계는 쓰지 않는다.
- 활동지에서는 빠졌지만 실제 수업에서 거치는 과정(예: 사이트 안의 단계)을 넣었으면 답 끝에 알린다.
- 자료에 없는 활동을 지어내지 않는다.

## 기준 예시 — 정보 · 인공지능 1차시 「인공지능이란?」 (2026-10-18)

이 예시의 말투와 분량을 기준으로 삼는다.

```text
<도입>
[동기유발]
∙ Quick, Draw!에 접속해 제시어 6개를 20초 안에 그리게 하고, AI가 몇 개를 알아맞히는지 짝과 대결하며 흥미를 유발한다.
∙ AI가 맞힌 개수를 활동지에 적고 발표하게 한 뒤, "컴퓨터는 처음 보는 내 낙서를 어떻게 알아맞혔을까요?"라는 탐구 질문을 제시한다.
∙ 탐구 질문에 대한 자기 생각을 활동지에 자유롭게 적게 한다.
[학습 주제 제시]
"유튜브·틱톡 추천과 인스타 필터 속 인공지능은 어떻게 똑똑해질까요?
인공지능과 인공지능 모델이 무엇인지 알아보고, 인공지능인 것과 아닌 것을 가려내 봅시다."

<전개>
[활동 1]
∙ 사람 뇌의 뉴런 연결과 인공 신경망을 비교한 그림과 짧은 애니메이션을 보여 주며, 인공 신경망이 데이터에서 패턴을 찾아 학습하는 과정을 설명한다.
∙ 인공지능, 인공 신경망, 인공지능 모델의 뜻을 정리한 표의 빈칸을 채우고, Quick, Draw!의 낙서 인식 사례와 연결하여 이해한다.
∙ Quick, Draw!의 AI가 낙서를 알아맞히기까지의 과정(데이터 수집 → 학습 → 모델 생성 → 예측)을 순서대로 배열한다.
∙ 인공 신경망, 학습, 인공지능 모델을 게임 실력에 빗댄 설명에 알맞은 이름표를 끌어다 놓으며 개념을 정리한다.
[활동 2]
∙ 일반 소프트웨어와 인공지능 소프트웨어를 비교한 그림을 제시하며, 둘을 가르는 기준이 '데이터로 학습했는가'임을 안내한다.
∙ 틱톡 추천 피드, 인스타그램 필터, 디데이 앱, 1/N 정산 기능 등 스마트폰 속 기능 8가지를 인공지능 소프트웨어와 일반 소프트웨어로 분류한다.
∙ 'AI'라고 불리지만 정해진 규칙대로만 움직이는 게임 몬스터 사례를 판단하며, 이름이 아니라 학습 여부로 구분해야 함을 확인한다.
[활동 3]
∙ code.org의 '바다를 위한 AI(AI for Oceans)'에 접속하여, 물고기와 쓰레기에 직접 라벨을 붙이며 AI를 학습시킨다.
∙ 학습 데이터를 더 많이 주었을 때 AI의 분류 결과가 어떻게 달라지는지 관찰한다.
∙ AI가 게, 문어, 거북 같은 바다 생물까지 '물고기 아님'으로 골라낸 까닭을 생각해 보며, AI는 학습한 데이터만큼만 판단할 수 있음을 이해한다.
[활동 4]
∙ 레이블, 학습 데이터, 테스트 데이터의 뜻을 시험공부(정답, 문제집, 처음 보는 시험 문제)에 빗대어 설명한다.
∙ 방금 체험한 AI for Oceans에서 레이블, 학습 데이터, 테스트 데이터에 해당하는 것을 찾아 연결한다.
∙ 영상 추천 AI의 성능을 확인할 때 학습에 쓰지 않은 새 데이터로 시험해야 하는 까닭을 생각해 본다.
∙ 잘못 붙은 레이블, 한쪽으로 치우친 사진, 시청 기록이 적은 새 계정 같은 사례를 '데이터 양 부족'과 '데이터 질 문제'로 분류하며, AI의 성능이 데이터의 양과 질에 좌우됨을 이해한다.

<정리>
∙ 오늘 배운 낱말(인공지능, 인공 신경망, 인공지능 모델, 레이블, 학습 데이터, 테스트 데이터)을 정리한 표의 빈칸에 이름표를 채워 넣으며 학습 내용을 정리한다.
∙ O/X 형성평가 6문항을 풀고, 바로 나오는 정답과 해설을 보며 자신의 이해 정도를 점검한다.
∙ 인공지능은 사람이 정한 규칙이 아니라 데이터로 학습한다는 점을 다시 강조하며, 인공지능 단원 학습의 기반을 다진다.
∙ 활동지를 PDF로 저장하여 제출한다.
```

## 참고 예시 — 다른 과목 지도안 (선생님 제공, 형식 참고용)

### 예시 1 (화학 — 분자 구조 영상 만들기 1차시)

```text
<도입>
[동기유발]
∙ Canva에서 교사가 직접 제작한 영상을 보여주며 흥미를 유발한다.
∙ 두 가지의 분자 구조 3D 이미지(예: CO2와 HCN)를 제시하며 탐구 질문을 제시한다.
"두 분자는 모두 직선형 구조를 가지지만, 왜 하나는 극성이 없고 다른 하나는 극성을 가질까요?"
[학습 주제 제시]
"AI와 디지털 도구를 활용해 우리가 선택한 분자 구조를
과학적으로 설명할 방법을 함께 구상해 봅시다."

<전개>
[활동 1]
∙ 조별로 5가지 구조(직선형, 굽은형, 삼각평면형, 삼각뿔형, 정사면체형) 중 하나를 선택한다.
∙ 해당 구조에 속하는 극성 분자 1종, 무극성 분자 1종을 선정한다. (무극성 분자가 없는 구조의 경우 극성 분자 2종을 선정한다.)
∙ MolView에서 선정한 분자의 2D・3D 구조를 탐색하고 이미지를 저장한다.
[활동 2]
∙ 조별로 Canva에 접속하여 공동 편집이 가능한 슬라이드를 생성하고, 역할을 분담 한다.
∙ 저장한 분자의 이미지(2D, 3D)를 불러와 슬라이드에 삽입한다.
∙ 슬라이드 내에서 '요소'를 삽입하여 그림에 쌍극자 모멘트를 표시하고, 구조적 특징을 시각적으로 표현한다.
[활동 3]
∙ 생성형 AI(ChatGPT)를 활용하여 선택한 분자의 구조와 성질에 대한 과학적 설명 스크립트를 생성한다.
∙ 프롬프트를 입력할 때 유의해야 할 점과 프롬프트의 예시를 안내한다.
<정리>
```

### 예시 2 (화학 — 분자 구조 영상 만들기 2차시)

```text
<도입>
[동기유발]
∙ 교사가 만든 시범 영상의 자막에서 ChatGPT가 생성한 오류 사례를 찾아보게 하며 오늘의 학습 방향을 안내한다.
∙ "AI가 만든 분자 구조 설명은 정말 과학적으로 타당할까?"라는 탐구 질문을 제시한다.
[학습 주제 제시]
"AI가 생성한 설명은 정말 과학적으로 타당할까요?
ChatGPT의 스크립트를 검증하고, 근거를 바탕으로 수정해 봅시다."

<전개>
[활동 1]
∙ ChatGPT가 생성한 스크립트를 검토하고 수정하는 과정에서 AI가 자주 범하는 오류 유형과 이에 대한 점검 방법을 안내한다.
∙ 조별로 ChatGPT가 생성한 스크립트를 교과서 및 신뢰할 수 있는 자료와 비교하여 검증한다.
∙ 오류 문장을 표시하고 수정 이유를 과학적으로 기록한다.
∙ '검증 기록지'에 초기 오류–검증 근거–수정 후 내용 순으로 정리한다.
[활동 2]
∙ 검증된 스크립트를 Canva 슬라이드에 적용한다.
∙ Canva의 AI 음성 기능을 사용하여 자연스러운 음성을 입힌다.
∙ 슬라이드 길이를 조정하여 음성 싱크를 맞춘다.
[활동 3]
∙ Canva의 자동 자막 기능을 이용해 자막을 생성한다.
∙ 전체 흐름을 미리보기로 점검하고 최종 영상을 완성한다.
<정리>
```

### 예시 3 (지구과학 — 기상 가상 실험)

```text
<도입>
[동기유발]
∙ 에듀넷 디지털 교과서에서 기압과 전선으로 풀어나가는 항해 모험이라는 AR 실험 구현하여 보여주기
[학습 주제 제시]
기상 관련 기초 지식을 에듀넷의 다양한 가상 실험으로 확인한다.

<전개>
[활동 1]
∙ 온실효과, 온난화 현상 등의 기초 지식을 교과서 중심으로 익히기
∙ 구름 발생 장치를 이용하여 단열팽창으로 생성되는 구름을 실험으로 확인한다.
[활동 2]
∙ 기후 감수성 프로젝트 운영을 위해 기후 및 날씨와 관련된 기초 지식을 탄탄히 하여 각종 데이터 해석을 용이하도록 한다.
[활동 3]

<정리>
∙ 디지털 도구를 활용하여 기후 개념에 대한 과학적 이해를 돕고, 기후 감수성 프로젝트의 기반을 다진다.
```
