## 세 탭 공통
- 날짜 카드 머리 #FBE3E8 / 몸통 #FFFDF8, 드롭다운 #FEF2F5(펼침 올림 #FBEFB4), 표·달력 머리 줄 #F3EAE0, 오늘 칸 #FFF6D6 + 잉크 3px + TODAY 꼬리표 #F6A8BC, 주말 휴무 #F3EAE0 글자 #6B5B51, 다른 달 #FAF2E1 글자 #857062.
- 메뉴 탭·보기 버튼·◀ ▶ 는 네모 칩(모서리 8px, 잉크 2px, 그림자 chip). 작은 글자(시각·달력 메뉴)는 #4A3B32 또는 #6B5B51 만 — #857062 는 16px 이상에서만.
- 한 화면 안에서 같은 색이 두 번 쓰이지 않도록 배치함: 이용 규칙은 11색 + 로즈 6단계 막대, 시간표·급식은 과목색 19·요일색 5가 파스텔을 쓰므로 태그·보기 버튼·드롭다운·NOTE 비과목 이름표는 흐린 톤(#EDE4D6 사암 · #F7E8DF 연복숭아 · #E9E2F0 연회보라 · #E3EBE6 연회민트 · NOTE #E6EEEA · #EFE6EE)만 쓴다. 핑크 #F6A8BC 는 「진행 중」·TODAY 꼬리표 전용 강조색.
