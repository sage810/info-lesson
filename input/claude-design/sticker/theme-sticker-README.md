# 테마: 스케치북 스티커 (theme-sticker)

**한 줄 분위기** — 크림색 스케치북 종이 위에 갈색 잉크로 선을 긋고, 파스텔 스티커를 붙인 듯한 포근한 활동지. 선은 또렷하게(1a), 그림자는 폭신하게(1b), PDF 버튼은 박음질 라벨처럼(1c).

## 글꼴 (역할 4개)
- 큰 제목: 강원교육모두 — 40px (「수업 활동지」·주제 카드 제목), 제목줄 26px
- 카드 제목·버튼: 쿠키런 Bold — 카드 제목 24px, 버튼·이름표·탭 17px, PDF 22px
- 본문: 메이플스토리 — 본문 17px, 단계 소제목 18px Bold(번호는 34px 핑크 #F6A8BC 반짝 별 안 정중앙, 쿠키런 16px), 작은 안내 16px
- 영문 라벨: Silkscreen — 16px, 글자 간격 1px, 한글 금지

## 모서리 · 테두리 · 그림자
- 모서리: 창 22 · 카드 18 · 상자/표/그림/PDF 14 · 입력칸 12 · 태그/빈칸 8 · 버튼/이름표/O/X/탭 999(알약)
- 테두리: 창 3px · 기본 3px · 작은 것(태그·빈칸·동전·안내 상자·표 안쪽) 2px, 전부 갈색 잉크
- 그림자: 전부 부드러운 번짐(1b). 창 0 14 34 / 카드 0 8 20 / 버튼 0 4 10 / 이름표 0 3 8 / 눌림 0 1 2, 색은 rgba(74,59,50,α). inset 없음.
- 점선: 이름표 모음 3px dashed #E0CBB0, 빈 칸 3px dashed #C9ADA1, PDF 박음질은 ::before 2px dashed rgba(74,59,50,.35)
- 장식: 카드 테두리 위 스티커 장식 없음. 메뉴 탭은 테두리 없이 분홍 트랙 안의 알약, 고른 탭은 흰 종이(1b).

## 움직임
- 길이 160ms 한 번. 마우스 올림 ↑2px, 누름 ↓1px, 이름표 놓임 pop(0.92→1.04→1).
- `prefers-reduced-motion: reduce` 이면 animation·transition 전부 없음.

## 하지 말 것 5가지
1. 어두운 배경·형광색 금지. 밝은 크림 바탕에 파스텔만.
2. `box-shadow: inset`, `color-mix()`, `oklch()`, `filter`, `backdrop-filter` 금지 (PDF 저장 깨짐).
3. 카드 머리 오른쪽에 아무것도 넣지 않는다. 영문 라벨에 한글 금지.
4. 16px 미만 글자 금지, 44px 미만 누르는 것 금지. 맞음·틀림은 색 + ✓ ✗ 기호 함께.
5. 치이카와 원작 캐릭터·로고 금지. 아이콘은 이 테마의 둥근 생물·스티커 세트만.
