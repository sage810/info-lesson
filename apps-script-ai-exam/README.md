# 인공지능 수행평가 전용 Apps Script (2026-11-04)

`ai/exam-a`(A형)·`ai/exam-b`(B형) 만 받는 **새 Apps Script · 새 시트**. 09 데이터분석 수행평가·NEIS 는 예전 `apps-script/` 그대로.
시트에 **수식이 하나도 없다** — 점수·총점·보정 총점은 이 코드가 숫자로 쓰고, PDF 는 링크 글자로 넣는다.

## 시트 「인공지능 수행평가 채점」 — 탭 6개

| 탭 | 내용 |
|---|---|
| 제출 | 학생이 낸 기록 원본(낼 때마다 한 줄) · PDF 링크 · 답(JSON) |
| 채점 A형 | 학생 한 줄 · 학년 반 번호 이름 · **총점 · 보정 총점** · 칸별 점수(1-1 … 3-3) · 저장 시각 · 출처 · PDF · 확인 |
| 채점 B형 | 위와 같음 |
| 결과 | 두 형을 모은 학년 · 반 · 번호 · 이름 · 총점 · 보정 총점 — 학년 → 반 → 번호 순. 점수·보정·제출이 바뀔 때마다 자동으로 다시 씀(손으로 고치면 지워짐) |
| 생기부 참고 | 두 형을 모은 학생 한 줄 · 형 · **3-2·3-3 점수와 학생 글**(문항별 한 칸, 가장 늦게 낸 것) · **메모**(선생님이 씀 — 다시 써도 지킴) · PDF — 학년 → 반 → 번호 순(선생님 결정 2026-11-10). 제출 때 그 학생 줄만 · 채점 도우미의 3-2·3-3 점수도 따라감 · 채점 도우미를 열 때와 아래 「다시 채우기」로 통째로 다시 씀 |
| 설정 | 보정 값 n(더할 점수)·x(최저)·y(최고) · 형별 칸·배점·채점 기준(`npm run exam-key` 가 보냄) |

- 같은 학생(학년·반·번호·이름)은 한 줄. 다시 내면 점수는 남고 **확인** 칸에 「다시 냄 — 점수 확인」, 채점 도우미는 가장 늦은 글을 보여 준다.
- 보정 총점 = 총점 + n, x 보다 작으면 x, y 보다 크면 y(x·y 는 비우면 안 씀). 채점 도우미 위쪽 칸에서 바꾸고 「적용」 → 두 형 모두 다시 계산.
- PDF 는 드라이브 「인공지능 수행평가 제출」 › `A형`·`B형` 폴더.

「생기부 참고」 다시 채우기: `<웹 앱 URL>?action=record&key=<TEACHER_KEY>` 를 열거나, 편집기에서 함수 **`생기부참고만들기`** ▶ 실행. 메모 칸 말고는 손으로 고치면 다시 쓸 때 지워진다.

## 처음 올리기 (한 번)

1. https://script.google.com → **새 프로젝트** → 이름 「인공지능 수행평가 API」.
2. 왼쪽 ⚙ **프로젝트 설정** → 「편집기에서 appsscript.json 매니페스트 파일 표시」 체크.
3. 편집기에서 `Code.gs` 내용을 모두 지우고 이 폴더의 `Code.gs` 를 붙여넣기 · `appsscript.json` 도 이 폴더 것으로 바꾸기 → 💾 저장.
4. ⚙ 프로젝트 설정 → **스크립트 속성** → 속성 추가: `TEACHER_KEY` = `teacher.local.json` 의 `teacherKey` 값(예전 것과 같아도 됨).
5. 편집기 위 함수 목록에서 **`setup`** 고르고 ▶ 실행 → 권한 허용(고급 → 이동) → 실행 로그에 폴더·시트 주소가 나온다.
6. 오른쪽 위 **배포 → 새 배포** → 유형 ⚙ **웹 앱** → 실행: **나** · 액세스: **모든 사용자** → 배포 → **웹 앱 URL 복사**.
7. 이 PC 에서 `lessons/ai/exam-a/lesson.json`·`exam-b/lesson.json` 의 `"apiUrl": ""` 에 그 URL 을 넣는다(Claude 에게 「주소 넣어줘」 해도 됨).
8. 채점 기준 보내기: `npm run exam-key -- ai/exam-a --send` · `npm run exam-key -- ai/exam-b --send` → 「설정」 탭에 칸·배점·기준.
9. 채점 도우미: `<웹 앱 URL>?action=teacher&key=<TEACHER_KEY>` (북마크).

`apiUrl` 이 비어 있으면 시험지가 아무 데도 보내지 않는다(예전 주소로 새지 않음). 넣은 뒤 `npm run build`.

## Code.gs 를 고쳤을 때

배포 → **배포 관리** → ✏ 편집 → 버전 **새 버전** → 배포. (「새 배포」를 누르면 주소가 바뀐다.)

이 PC 의 clasp(학교 계정 로그인)로도 된다 — scratchpad 에 `clasp clone <스크립트 ID>` → `Code.js` 를 이 폴더 `Code.gs` 로 바꿔 넣고 `clasp push` → `clasp create-version "설명"` → `clasp update-deployment <apiUrl 의 AKfycb… 배포 ID> -V <새 버전>`(주소 그대로) → 주소를 열어 `version` 이 `Code.gs` 의 `VERSION` 과 같은지 확인(2026-11-10 생기부 참고 때 이렇게 올림). 올리기 전에 clone 한 `Code.js` 가 이 폴더 `Code.gs` 와 같은지(다른 사람이 편집기에서 고친 게 없는지) 먼저 비교한다.
