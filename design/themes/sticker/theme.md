# 테마 sticker — 스케치북 스티커

크림색 스케치북 종이 위에 갈색 잉크로 선을 긋고, 뽀얀 파스텔 스티커를 붙인 듯한 활동지.
원본: `input/claude-design/sticker/`(Claude Design, 2026-10-21 · 견본 `theme-sticker.html`, 값 표 `theme-sticker-tokens.md`·`theme-sticker-tabs-tokens.md`).

- 쓰기: 차시 `lesson.json` 에 `"theme": "sticker"` · 미리보기 `npm run template-preview -- order --theme sticker` → http://127.0.0.1:8080/_preview/template-order/
- **디자인 토큰 한 벌**: `design-sticker/`(2026-10-22 — 다른 웹앱용 tokens.css·부품·미리보기, 새 차시 쓰는 법, ai/01 에서만 넣은 장식 골라 쓰기). 여기 값을 고치면 `design-sticker/tokens.json` 도 같이.
- 틀(`_templates/order`)과 거기서 만든 차시용. **ai/01 이 이 테마를 쓴다**(선생님 결정 2026-10-22 — 내용은 그대로, 모양만 변수로 바꿔 입힘).

## 변수로 바꾼 것
- 색: 바탕 크림 `#FAF2E1` · 잉크 갈색 `#4A3B32`(`--msi-rgb-ink: 74,59,50`) · 카드 12벌(위→아래 따뜻함·차가움 교대) · 버튼 · 채점 · 세 탭(과목 19 · 알레르기 19 · 요일 5 · 보기 버튼 3).
- 모양: 모서리 창 22 · 카드 18 · 상자·표·그림 14 · 입력칸 12 · 태그 8(`radius-k 1.35` + r16·r14·r12·r11·r10·r9·r6 덮어쓰기) · 창 테두리 4→3px ·
  그림자는 어긋난 그림자 대신 아래로 번짐(`sh1`~`sh8` = `0 Ypx blur`).
- 유리 층(`--msi-glass-*`)·오로라 빛(`aurora-*-aNN`)은 끔 — 평평한 종이.
- 「진행 중」 배지 `base-live-violet` = `#B04A6C`(크림 글자 5.2:1). 견본은 분홍 배지 + 잉크 글자지만, 틀은 배지 글자가 크림색이라 대비를 맞춰 진한 장미색으로.

## 선택자 규칙으로 더한 것
- 바깥 배경 점무늬(모눈·오로라 대신) · 창·주제 카드의 흰 테·오로라 빛 끔
- 제목줄 세로 줄무늬(`titlebar-head` 값) · 창 단추 → 버터·민트·살몬 동그라미
- 제목줄 학교 아이콘 🏫 → `app-icon.png`(선생님 피드백 2026-10-21, 받은 그림을 128px 로 줄임). 틀의 `<span class="app-ic">` 를 글자 크기 0 + 배경 그림으로.
  치이카와 원작 캐릭터 그림 — 공개 사이트에 쓰는 것은 선생님이 정함(2026-10-21).
- 아이콘 그림 `icons/`(선생님 피드백 2026-10-21, 받은 그림 → 분홍 바탕 지우기 · 자르기 · 128px) — 틀의 `data-ic` 자리:
  메뉴 탭 📜 `tab-rules` · 🕒 `tab-time`(2026-10-22) · 🍚 `tab-meal` · ✏️ `tab-sheet` / 🎯 `ic-target` / 카드 🎨 `ic-palette` · 🔎 `ic-search` · 🧠 `ic-brain` · 🤖 `ic-robot` · 🌊 `ic-wave` · 🍚 `ic-rice` · 📝·✅ `ic-check`.
  카드 아이콘 칸은 이 테마에서 30 → 40px.
- 메뉴 탭: 분홍 트랙 안의 알약, 고른 탭은 흰 종이(견본 1b) — 네모 칩 시안(B)과 비교해 이쪽으로 선생님 결정(2026-10-22, 시안 A). 탭 모양은 `tabChip()` 인라인이라 `!important`. 폰(≤560px)은 2×2 라 트랙 모서리 18.
- 단원 이름 버터 알약 · 번호 동전 말풍선(SVG data URI — PDF 에도 나옴) · 순서 ①~④ 말랑 네모 · 이름표 놓는 칸 알약
- 버튼·이름표 테두리 3px, 올리면 ↑2px, 누르면 ↓1px · ✅ 확인 = 민트 · ↗ 바깥 사이트 = 베이비블루
- 키보드 포커스 분홍 3px 고리(▶ 깜박임은 그대로) · 진행률 막대 분홍
- PDF 버튼: 박음질 라벨(둥근 네모 + 안쪽 점선 `::after` + 분홍 번짐 그림자), 처리 중 버터 · 끝남 민트 · 실패 살몬
